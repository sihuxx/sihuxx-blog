## 1. 사용 이유

- 한 프로젝트에서 여러명이 함께 작업할 때 만들어지는 모든 커밋들이 한 라인에 놓이면 매우 혼란스러워짐 
- 코드가 서로 충돌하거나 꼬이고, 당장 해결해야 할 버그가 있는데 진행중인 다른 작업 때문에 출시 못하는 등 문제 발생
	- 이를 방지하기 위해 각 작업들을 분리된 공간에 격리하여 진행할 필요 존재
## 2. 브랜치

> 기존 코드를 망가뜨리지 않고 독립적으로 기능을 개발하거나 버그를 수정할 수 있도록 만드는 가벼운 작업 영역


![[Pasted image 20261120163212.png]]
**명령어**
- `git branch 브랜치명`: 새 브랜치 생성하는 명령어
- `git branch`: 로컬 브랜치 목록 보여주는 명령어
- `git switch 브랜치명`: 현재 브랜치 변경하는 명령어
- `git switch -c 브랜치명`: 새 브랜치 생성과 동시에 생성된 브랜치로 현재 브랜치 변경하는 명령어
- `git branch -d 브랜치명`: 브랜치를 삭제하는 명령어 (삭제할 브랜치와 다른 브랜치에 위치해 있어야 한다)
- `git branch -m 브랜치명 바꿀 브랜치명`: 브랜치명을 변경하는 명령어
- `git branch -D 브랜치명`: 대상 브랜치와 그곳에서 진행된 작업 모두 강제 삭제하는 명령어
