## 1. 파일 종류별 git 관리 기준

| 구분            | 해당 파일                                                  | 이유                    |
| ------------- | ------------------------------------------------------ | --------------------- |
| 맡기지 않아도 되는 파일 | `dist` 폴더, 패키지 관리 프로그램이 자동 생성하는 파일 (예: `node_modules`) | 명령어 한 번이면 다시 만들어지는 파일 |
| 맡기면 불편한 파일    | 컴퓨터마다 다르게 작성되어야 하는 환경설정 파일                             | 팀원끼리 덮어쓰며 충돌 발생       |
| 맡기면 안 되는 파일   | API 키, 비밀번호 등 민감 정보가 담긴 `.env` 파일                      | 저장소에 올라가면 외부 유출 위험    |

## 2. .gitignore

- git이 추적하지 않을 파일과 폴더를 적어두는 파일
- 프로젝트 루트 폴더에 `.gitignore` 이름으로 생성

```gitignore
# 단일 파일
config.py

# dist 폴더 안의 모든 파일
dist/

# 파일명이 secrets인 모든 파일 (확장자 무관)
secrets.*
```
