## 1. 컴퓨터 사용자 설정

> `git config --global user.name`

- git 관련 명령어들은 모두 `git`으로 시작
- `config`: `configulation`의 줄임말, git 관련 각종 설정 할 때 사용하는 명령어
- `global`: 전역, 특정 프로젝트에 국한되지 않고 컴퓨터 전체에 적용된다는 의미

## 2. 브랜치명 설정

> `git config --global init.defaultBranch main`

- branch의 기본 브랜치명인 `master`가 노예제를 연상시키기에 `main`으로 초기화시키는 과정

## 3. 폴더 git 설정

- `git init`: git 저장소를 초기화하는 명령어
- `git status`: 프로젝트 상태 물어보는 명령어
