## 1. 명령어 정리

|명령어|역할|비고|
|---|---|---|
|`git status`|프로젝트의 현재 상태 확인|어떤 파일이 바뀌었는지, 스테이징됐는지 표시|
|`git add .`|변경된 모든 파일을 스테이징(커밋 대기 상태)에 올림|커밋 직전에 담는 단계|
|`git commit`|스테이징된 변경사항을 하나의 버전으로 저장|메시지 없이 실행하면 Vi 에디터가 열림|
|`git commit -m "메시지"`|에디터 없이 메시지까지 한 번에 입력하는 커밋||
|`git commit -am "메시지"`|`add` + `commit`을 한 번에 처리|새로 만든 파일이 없고, 이미 git이 추적 중인 파일만 수정했을 때 사용|
|`git log`|커밋 목록 확인|내역이 길면 `j`/`k`로 스크롤, `q`로 종료|
|`git diff`|지난 버전과 비교한 변경 내용 확인|마찬가지로 `j`/`k`로 스크롤, `q`로 종료|

- **Git 해시**: 커밋마다 붙는 고유 일련번호, 특정 시점으로 되돌릴 때 식별자로 사용

## 2. Vi 명령어

|작업|Vi 명령어|상세|
|---|---|---|
|입력 시작|`i`|명령어 입력 모드에서 텍스트 입력 모드로 전환|
|입력 종료|`ESC`|텍스트 입력 모드에서 명령어 입력 모드로 전환|
|저장 없이 종료|`:q`||
|저장 없이 강제 종료|`:q!`|입력한 것이 있을 때 사용|
|저장하고 종료|`:wq`|입력한 것이 있을 때 사용|
|위로 스크롤|`k`|`git log` 등에서 내역이 길 때 사용|
|아래로 스크롤|`j`|`git log` 등에서 내역이 길 때 사용|
