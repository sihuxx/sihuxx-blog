## 1. VCS (Version Control System)

**개념**
- 버전 관리 시스템
- 개발 중인 프로그램의 변경 이력을 시점별로 저장하고 관리하는 도구
- 압축파일로 중간중간 백업하는 방식의 자동화된 상위 버전

## 2. Git을 쓰는 이유

### 1. 원하는 시점으로 복구

- 기능 업데이트 후 오류가 생겼을 때, 정상 동작하던 마지막 시점으로 되돌리는 작업
- 중요 지점마다 버전을 커밋해두면 언제든 해당 시점으로 복귀 가능

### 2. 분기(브랜치) 개발

- 프로그램을 여러 갈래로 나눠 각각 독립적으로 개발 가능
- 원본은 그대로 유지한 채 새 기능 실험 후, 마음에 들면 합치고 아니면 폐기
