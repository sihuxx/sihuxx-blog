## 1. 충돌 이유

- 두 브랜치가 **같은 파일의 같은 부분**을 다르게 수정했을 때 Git이 자동으로 합치지 못하는 상황
- 충돌 파일 내에 아래 표시가 생김
```
<<<<<<< HEAD
현재 브랜치의 내용
=======
합치려는 브랜치의 내용
>>>>>>> feature
```
- 충돌한 내용은 현재 브랜치의 내용, 합치려는 브랜치의 내용, 혹은 둘 모두의 내용 각각의 선택지 중 직접 선택 가능
## 2. 충돌 해결

### merge

```bash
git switch main
git merge feature # CONFLICT 발생
```

1. `git status`로 충돌 파일 확인 (`both modified`로 표시)
2. 파일을 열어 최종 내용 직접 수정 (선택)
3. `git add 파일명`
4. `git commit` (또는 `git merge --continue`)로 병합 커밋 생성

- 중단하고 싶을 때: `git merge --abort` (합치기 전 상태로 복귀)
- 충돌 해결은 **한 번**으로 끝

### rebase

```bash
git switch feature
git rebase main # CONFLICT 발생
```

1. `git status`로 충돌 파일 확인
2. 파일을 열어 충돌 표시를 지우고 최종 내용으로 수정
3. `git add 파일명`
4. `git rebase --continue` (**`git commit` 하면 안 됨**)

- 중단하고 싶을 때: `git rebase --abort` (rebase 전 상태로 복귀)
- 문제 커밋을 건너뛸 때: `git rebase --skip` (해당 커밋 내용은 버려짐)
- 커밋을 하나씩 옮기면서 적용해서 **커밋마다 충돌이 반복**될 수 있음, 각 단계마다 2~4번 반복
