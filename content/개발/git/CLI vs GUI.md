## 1. CLI

> Command Line Interface

- 텍스트로 명령어를 입력하여 컴퓨터에게 지시 내리는 방식
- 예시: 터미널, 명령 프롬프트, GIt Bash
## 2. GUI

> Graphical User Interface

- 아이콘, 버튼, 창 등 시각적으로 직관적인 요소들을 마우스로 클릭하거나 손가락으로 터치하여 사용하는 방식
	- 예시: 윈도우 바탕화면, 스마트폰 앱

| 구분     | CLI                    | GUI                              |
| ------ | ---------------------- | -------------------------------- |
| 풀네임    | Command Line Interface | Graphical User Interface         |
| 조작 방식  | 텍스트 명령어 입력             | 아이콘·버튼·창을 클릭                     |
| 예시     | 터미널, 명령 프롬프트, Git Bash | 윈도우 바탕화면, 스마트폰 앱, GitHub Desktop |
| 난이도    | 초반에 어려움                | 직관적이라 쉬움                         |
| 속도·자동화 | 유리                     | 상대적으로 불리                         |
