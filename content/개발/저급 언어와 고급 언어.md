## 1. 개념
#### 저급 언어

> 컴퓨터가 직접 이해할 수 있는 기계어에 가까운 언어, 수준이 낮다는 뜻이 아닌 하드웨어와 가깝다는 의미

**특징**
- 컴퓨터가 바로 이해하므로 실행 속도가 매우 빠름
- 하드웨어를 직접 제어할 수 있어 세밀한 조작 가능
- 사람이 읽고 이해하기 매우 어렵고 배우기 까다로움
- 하드웨어 종류에 따라 코드가 달라져 호환성이 낮음

**종류**
- 기계어
- 어셈블리어

#### 고급 언어

> 사람이 직관적으로 이해하고 작성하기 쉽게 영어 단어와 기호 중심으로 만들어진 언어

**특징**
- 사람이 배우고 사용하기 쉬움
- 하드웨어 세부 내용을 몰라도 프로그램 만들 수 있음
- 코드가 짧고 명확하여 유지보수가 편함
- 컴퓨터가 실행하려면 번역기([[자바란#^58dc63|컴파일러]], [[자바란#^9a2a75|인터프리터]])를 거쳐야 하므로 저급 언어보다 실행 속도 약간 느릴 수도 있음
- 특정 하드웨어 종속되지 않고 독립적으로 작동
