## 1. 추상 클래스

**규칙**
- `abstract class`로 선언, `extends`로 상속
- 추상 메소드를 포함하지 않은 클래스에서도 `abstract`를 붙여서 추상 클래스로 지정할 수도 있다.
- 클래스는 abstract로 지정하면 `new`를 통해 객체를 직접 생성할 수 없다.
- 메소드에 abstract를 사용할 경우 interface의 메소드와 같이 구현 부분은 없다.
- abstract로 선언한 메소드를 자식 클래스에서 반드시 구현해야 한다. (오버라이딩) 이는 자식 클래스에서 추상 메소드를 반드시 구현하도록 강제하는 것이다.

**사용 의도**
공통 기능을 물려주고 빈칸(추상 메서드)만 자식이 채우는 구조

## 2. 인터페이스

**규칙**
- `interface`로 선언, `implements`로 구현
- 여러 개 구현이 가능하다. (다중 구현)
- 생성자와 일반 필드가 존재하지 않는다.
- 모든 멤버 변수는 `public static final`이어야 하며, 이를 생략할 수 있다.
- 모든 메소드는 `public abstract`이어야 하며, 이를 생략할 수 있다.

**사용 의도**
서로 다른 클래스에 같은 기능을 약속하고 구현을 강제하는 구조

## 3. 차이점

```java
abstract class Animal { // 추상 클래스
    String name; // 필드 가능
    void breathe() { // 일반 메서드 가능
        System.out.println("숨쉬기");
    }
    abstract void sound(); // 추상 메서드
}

interface Swimmable { // 인터페이스
    void swim(); // 추상 메서드
}

class Dog extends Animal implements Swimmable { // 상속 + 구현
    void sound() { System.out.println("멍멍"); } // 추상 메서드 구현
    public void swim() { System.out.println("개헤엄"); } // 인터페이스 메서드 구현
}
```

**존재 목적**
**추상 클래스**의 존재 목적은 추상 클래스를 상속 받아서 기능을 이용하고 확장시키는 데 있다.
**인터페이스**의 존재 목적은 함수의 껍데기만 가지고 있으면서 함수의 구현을 강제하고 결과적으로 구현 객체의 같은 동작을 보장하기 위함이다.

**다중 구현**서로 다른 클래스들이 같은 기능을 가져야 할 때

**상황에 따른 구분**
- 추상 메소드만 선언 한다면 -> **인터페이스**, 다른 일반 메소드나 필드도 필요하면 -> **추상 클래스**
- 같은 종류나 행동들을 구현할 것이 많을 때 -> **추상 클래스**
- 상속에 대한 계층구조를 명확히 표현하고자 한다면 -> **추상 클래스**
- 디자인을 구성하는 요소들이 자주 바뀔 때 -> **인터페이스**
- 서로 다른 클래스들이 같은 기능을 가져야 할 때 -> **인터페이스**

| 구분        | 추상 클래스                      | 인터페이스                                      |
| --------- | --------------------------- | ------------------------------------------ |
| **키워드**   | `abstract class`, `extends` | `interface`, `implements`                  |
| **개수**    | 하나만 상속 가능                   | 여러 개 구현 가능                                 |
| **필드**    | 일반 필드 가능                    | 상수만 가능 (`public static final`)             |
| **생성자**   | 있음                          | 없음                                         |
| **메서드**   | 일반 메서드 + 추상 메서드             | 추상 메서드 + `default`, `static` 메서드 (Java 8+) |
| **객체 생성** | `new`로 직접 생성 불가             | `new`로 직접 생성 불가                            |
| **목적**    | 공통 기능 물려주기 + 확장             | 같은 동작 보장 (구현 강제)                           |
