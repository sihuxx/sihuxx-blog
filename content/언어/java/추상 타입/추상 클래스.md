> 아직 완성되지 않은 클래스

**특징**
- new 연산자를 사용해 직접 인스턴스를 만들 수 없어 객체 생성이 불가능하다.
- 클래스 선언 시 `abstract` 키워드를 붙인다. 내부에 구현부가 없는 추상 메소드를 포함할 수 있다.
- 자식 클래스는 부모 클래스의 추상 메소드를 반드시 오버라이딩 해야 한다.
- 추상 메소드 뿐만 아니아 일반 필드, 생성자, 메서드도 함께 가질 수 있다.

**사용 목적**
- 코드 중복 제거 및 재사용
- 구현 강제화
- 일관된 설계 구조

**형태**
```
abstract class 클래스명 {

}
```

```java
abstract class Shape {
	abstract double calculateArea();
}

class Square extends Shape {
	private double s;
	public Square(double s) {
		this.s = s;
	}
	double calculateArea() {
		return s * s;
	}
}

class Circle extends Shape {
	private double r;
	public Circle(double r) {
		this.r = r;
	}
	double calculateArea() {
		return Math.PI * r * r
	}
}
```
