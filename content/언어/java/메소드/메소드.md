> 특정 기능을 수행하기 위한 코드의 묶음

## 1. 메소드

- 형태: 
```
접근제어자 반환형 메소드명(전달값) {
	명령문1
	명령문2
}
```

```java
public static void print() {
	System.out.println("안녕?");
}
public static void main(String[] args) {
	print(); // 메소드 호출
}
```

## 2. 전달값 (parameter)
> 메소드 호출 시 전달하는 값

```
접근제어자 반환형 메소드명(**전달값**) {
	명령문1
	명령문2
}
```

```java
public static void print(int a) { // 전달값이 있는 메소드
	System.out.println(a);
}
public static void add(int a, int b) { // 전달값이 여러개 있는 메소드
	System.out.println(a + b);
}
public static void main(String[] args) {
	print(3); // 메소드 호출
	add(1, 2); // 3
}
```
- **매개변수**: 메서드 정의 쪽에서 받는 변수 -> `add(int a, int b)`의 a, b
- **인자**: 호출할 때 실제로 넘기는 값 -> `add(1, 2)`의 1, 2

## 3. 반환값
> 메소드 실행 결과를 반환

```
접근제어자 **반환형** 메소드명(전달값) {
	명령문1
	명령문2
	
	**return 반환값**
}
```

```java
public static int getNumber() {
	return 45;
}
public static void main(String[] args) {
	int num = getNumber();
	System.out.println(num); // 45
}
```

## 4. 메인 메소드
```java
public static void main(String[] args) {
	...
}
```
- 자바로 작성한 소스 코드 파일 실행 시 가장 먼저 실행되는 메소드 (= 진입점 함수)

## 5. void
> 메소드가 실행된 후 호출한 곳으로 반환하는 값이 없음을 나타내는 키워드

**특징**
- **반환값 없음**: 메소드가 어떤 작업을 수행하나, `return` 키워드를 사용하지 않음
- **변수 대입 불가**: 결과값이 없으므로 `String a = print();` 처럼 변수에 저장 불가
- **단독 return 사용 가능**: 값 반환은 불가능하나 메소드를 중간에 강제 종료할 때 `return` 단독 사용 가능
```java
public void checkAge(int age) {
    if (age < 0) {
        System.out.println("Invalid age");
        return;  // 메소드 종료
    }
    System.out.println("Age: " + age);
}
```

**사용하는 경우**
- 화면 출력 같은 단순 실행 목적
- 객체 내부 상태 변경 작업일 때
- 외부에 값을 전달할 필요가 없는 동작일 때
