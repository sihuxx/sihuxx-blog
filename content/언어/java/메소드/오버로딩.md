## 1. 오버로딩
> 같은 이름, 다른 매개변수

- **정의**: 메소드 이름이 같아도 매개변수의 개수나 타입이 다르면 서로 다른 메소드로 인식한다.
- **목적**: 하나의 이름으로 비슷한 동작을 하는 여러 기능을 구현하여 코드의 가독성을 높이고 일관성을 유지한다.

```java
public static int add(int a, int c) {
	return a + b;
}
public static int add(int a, int b, int c) {
	return a + b + c;
}
public static double add(double a, double b) {
	return a + b;
}

public static void main(String[] args) {
	System.out.println(add(1,2));
	System.out.println(add(1,2,3));
	System.out.println(add(0.2, 1.1));
}
```

**오버로딩 조건**
- 메소드 **이름**이 같아야 한다.
- 매개변수의 **개수**가 달라야 한다.
- 매개변수의 **타입**(자료형)이 달라야 한다.
