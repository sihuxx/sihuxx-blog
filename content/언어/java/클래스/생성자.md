> 객체가 생성될 때 자동으로 호출되는 메소드

## 1. 생성자

- 클래스 이름과 동일한 이름을 사용
- 반환 타입을 명시하지 않음
- 호출 시점: new 클래스이름() 을 통해 객체를 생성할 때 단 한번 자동으로 호출됨 
```
클래스명(전달값) {
	초기화 명령문
}
```

```java
class Person {
	String name;
	int age;
	Person(String name, int age) { // 생성자
		// 초기화 작업
		this.name = name;
		this.age = age;
	}
}

public static void main(String[], args) {
	Person person = new Person("시후", 18);
}
```

**기본 생성자**
> 클래스 내부에 생성자를 따로 정의하지 않으면, 자동으로 매개변수가 없는 기본 생성자를 만들어줌 
```java
public class Car {
// 생성자를 작성하지 않아도 자동으로 기본 생성자가 제공됨
}
```

```java
Car car = new Car(); // 기본 생성자 호출
```

**매개변수가 있는 생성자**
> 객체 생성과 동시에 값을 초기화하고 싶다면 매개변수가 있는 생성자 정의할 수 있음
```java
public class Person {
    String name;
    public Person(String name) {
        this.name = name;
    }
}
```

```java
Person p = new Person("시후");
```

## 2. 오버로딩
> 같은 클래스명을 지니고 있지만 매개변수가 다른 생성자 여러개 정의 가능

```java
public class Person {
    String name;
    int age;
 
    public Person() { // 기본 생성자
	    // ...
    }
    public Person(String name) { // 매개변수 1개 생성자
        this.name = name;
    }
    public Person(String name, int age) { // 매개변수 2개 생성자
        this.name = name;
        this.age = age;
    }
}

// 각각 모두 다른 생성자
```

## 3. [[this#^9ed6be|this()]]
같은 클래스에서 **생성자가 다른 생성자를 호출할 때 사용**
- 주로 코드의 중복을 줄일 목적으로 사용
- 생성자 코드에서만 사용할 수 있음
- 생성자 코드 안에서 사용될 때 **첫번째 문장으로 다른 코드보다 가장 윗줄에 위치**해야 함

**예제 코드**
```java
public class Book {
    private String title;
    private int price;
 
    public Book(String title, int price) {
        this.title = title;
        this.price = price;
    }
 
    public Book(String title) {
        this(title, 0);
    }
}
```
