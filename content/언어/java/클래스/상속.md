## 1. 상속

> 특정 클래스의 기능을 재사용 및 확장

- 기존 클래스에 기능을 추가하거나 재정의하여 새로운 클래스를 정의하는 것
- 코드의 중복을 줄여주고 개발시간 단축을 통해 효율성 높임
- 접근 제한자에 따라 상속을 받아 접근할 수 있는 필드와 메소드는 달라질 수 있음

![[Pasted image 20261013193325.png]]

```
class 자식 클래스명 extends 부모 클래스명 {
	...
}
```

```java
class Student extends Person {
	String school;
}
```

## 2. 메소드 오버라이딩
> 부모 클래스의 메소드 재정의

- 상위 클래스가 가지고 있는 메소드를 하위 클래스가 재정의해서 사용하는 것
- 메소드의 이름, 파라미터 개수, 타입이 동일해야 함
- 주로 상위 클래스의 동작을 상속받는 하위 클래스에서 변경하기 위해 사용
- 부모 - 자식 상속 관계에서만 성립

```java
class Person {
	public void introduce() {
		System.out.println("사람입니다");
	}
}

class Student extends Person {
	public void introduce() { // student 클래스가 부모 메소드를 덮어써서 새로운 메소드를 정의함
		System.out.println("학생입니다");
	}
}
```

## 3. 다형성
> 여러 형태로 다시 동작할 수 있는 성질

**장점**
- 여러 객체를 하나의 타입으로 관리할 수 있어 유지보수가 용이
- 객체의 재사용이 쉬워 재사용성이 높아짐
- 클래스 간 의존성을 줄여 확장성은 높아지고 결합도는 낮아짐

**조건**
- 상위 클래스와 하위 클래스는 **상속 관계**여야 함
- 다형성이 보장되기 위해 **오버라이딩**이 반드시 필요하다.
- 자식 클래스의 객체가 부모 클래스의 타입으로 형변환 해야 한다. (**업캐스팅**)

```java
class Person {
	public void introduce() {
		System.out.println("사람입니다");
	}
}

class Student extends Person {
	public void introduce() { 
		System.out.println("학생입니다");
	}
}

public class main {
	public static void main(String[] args) {
		Person person = new Person();
		Person student = new Student();
		// 타입 이름 = new 생성자()
		Person student = new Student();
		student.introduce(); // 학생입니다 (오버라이딩된 자식 메소드 실행)
		student.study();  // 에러 (Person에 없는 메서드)
	}
}
```

- 부모 타입 참조 변수로는 부모 클래스에 있는 변수와 메소드만 사용 가능
	- 단, 자식 클래스가 오버라이딩한 메소드는 자식 클래스의 메소드로 실행
	- 자식 클래스에만 있는 메소드는 호출 불가

## 4. super
> 부모 클래스 접근

```
super.부모 클래스 변수;
super.부모 클래스 메소드();
super();
```

**super** (부모의 멤버 참조)
- 자식 클래스에서 부모 클래스의 변수나 메소드와 이름이 중복될 때, **부모의 것을 명확히 가리키기 위해** 사용
- 오버라이딩된 부모의 메소드를 자식 메소드 내부에서 호출할 때 유용
```java
class Parent {
    int value = 10;
    void print() { System.out.println("부모"); }
}

class Child extends Parent {
    int value = 20;

    void show() {
        System.out.println(value); // 자식의 value
        System.out.println(super.value); // 부모의 value
        super.print(); // 부모의 print() 호출
    }
}

```

**super()** (부모의 생성자 호출)
- 자식 클래스의 생성자에서 **부모 클래스의 생성자를 호출**할 때 사용
- 자식 클래스의 객체가 생성될 땐 부모의 생성자가 먼저 실행되어야 함

```java
class Person {
	int age;
	Person(int age) {
		this.age = age;
	}
}

class Student extends Person {
	String school;
	Student(int age, String school) {
		// this.age = age;
		super(age); // 부모 클래스의 생성자를 자동으로 호출해줌
		this.school = school;
	}
}
```
