> 상수들의 묶음

**특징**
- 상수로 구성된 특별한 클래스
- 클래스 처럼 변수와 메소드를 가질 수 있지만, 상속이나 인스턴스를 생성할 수는 없으며, enum 값은 상수로 public, static, final 속성을 가지고 있어 변경될 수 없음.

**장점**
- 데이터 값의 의미를 명확히 알 수 있음
- 컴파일 시 데이터 타입 및 유효성 체크를 할 수 있음

**메소드**
- **valueOf(String str)**: 문자열 str과 일치하는 열거값을 반환
- **values()**: 열거값 전부를 배열로 반환
- **ordinal()**: 열거값의 순서 반환

```
enum 열거형명 {
	상수명1
	상수명2
	...
}
```

```java
enum Gender {
	MALE,
	FEMALE
}

class Person {
	Gender gender;
	public void setGender(Gender gender) {
		this.gender = gender;
	}
	public static void main(String[] args) {
		Person person = new Person();
		person.setGender(Gender.MALE);
		
		switch (person.gender) {
			case MALE: System.out.println("남자"); break;
			case FEMALE: System.out.println("여자"); break;
		}
	}
}
```
