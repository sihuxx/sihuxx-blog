## 1. 클래스
> 데이터와 기능을 포함하는 코드 묶음

- 프로그램에서 사용될 객체의 틀을 정의하고, 객체를 생성하기 위한 설계도 역할
- **클래스**: 객체를 만들기 위한 정의와 구조
- **객체**: 클래스로부터 만들어진 실체 (인스턴스)

```
class 클래스명 {
	...
}
```

```java
class Person {
	...
}

public static void main(String[] args) {
	Person person1 = new Person();
}
```

## 2. 인스턴스 변수
> 클래스 내에 선언된 변수

```
class 클래스명 {
	인스턴스 변수1;
	인스턴스 변수2;
}
```

```java
class Person {
	String name;
	int age;
}

public static void main(String[] args) {
	Person person = new Person();
	person.name = "시후";
	person.age = 18; 
	// 점(.)으로 인스턴스 변수에 접근 
}
```
- 인스턴스 변수는 동일한 클래스로 생성된 각 객체마다 다른 값을 가질 수 있다

## 3. 클래스 변수
> 클래스 내에 static으로 선언된 변수

```
class 클래스명 {
	static 인스턴스 변수1;
	static 인스턴스 변수2;
}
```

```java
class Person {
	static int personCount = 0;
}

public static void main(String[] args) {
	Person.personCount = 10;
	System.out.println(Person.personCount);
} 
```
- 객체 만들 필요 없이 클래스 명으로 접근

## 4. 인스턴스 메소드
> 클래스 내에 정의된 메소드

```
class 클래스명 {
	인스턴스 메소드1;
	인스턴스 메소드2;
}
```

```java
class Person {
	String name;
	int age;
	public void introduce() {
		System.out.println("이름: " + name);
		System.out.println("나이: " + age);
	} 
}

public static void main(String[] args) {
	Person person1 = new Person();
	person.name = "시후";
	person.age = 18; 
	person.introduce();
	/*
	이름: 시후
	나이: 20
	*/
	// 점(.)으로 인스턴스 메소드에 접근 
}
```

## 5. 클래스 메소드
> 클래스 내에 static으로 정의된 메소드

```
class 클래스명 {
	static 클래스 메소드1;
	static 클래스 메소드2;
}
```

```java
class Person {
	String name;
	int age;
	static int personCount = 0;
	public static void printPersonCount() {
		System.out.println(personCount);
	} 
}

public static void main(String[] args) {
	Person.personCount = 10;
	Person.printPersonCount(); // 10
}
```
