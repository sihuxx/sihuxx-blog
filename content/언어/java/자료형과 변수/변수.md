#java

## 1. 변수

> 자료 (값)를 저장하기 위한 공간

- 형태: `자료형 변수명 = 값;`

**변수 선언**
```java
String name = "시후";
int age = 18;
double score = 90.5;
char grade = 'A';
boolean pass = true;
// 선언과 동시에 초기화
```

```java
int age;
age = 28;
// 선언 따로, 값 저장 따로
```

**변수명**
1. 밑줄 ( _ ), 문자 (abc), 숫자 (123) 사용 가능 (공백 사용 불가)
2. 밑줄 또는 문자, $로 시작 가능
3. 숫자로 단어 시작 불가능
4. 한 단어 또는 2개 이상 단어의 연속 `(권장사항)`
5. 소문자로 시작, 각 단어의 시작 글자는 대문자 (= 카멜케이싱, 첫 단어 제외) `(권장사항)`
6. 예약어 사용 불가 (public, static, void, int, double, float, ...)
7. 대소문자 구분 (myname != myName)

**상수**
> 변하지 않는 값

- 형태: `final 자료형 변수명 = 값`
```java
final int age = 18;
age = 28; // 값 변경 불가
```

**형 변환**
> 정수, 실수, 문자열 간 변환

- 형태: `(자료형) 변수명 or 값`

- **묵시적 형 변환**: 자동 형 변환
```java
int score = 93;
float score_f = (float) score;
double score_d = (double) 93;
```
`int -> long -> float -> double`

- **명시적 형 변환**
```java
double score_d = 98.8;
int score = (int) score_d
```

## 3. 스코프

> 기본 규칙: 변수는 자기가 선언된 `{ }` 블록 안에서만 쓸 수 있음

```java
public static void main(String[] args) { // 블록 A
    int a = 1;

    if (true) { // 블록 B
        int b = 2;
        System.out.println(a);  // OK: 바깥(A) 변수는 안에서 보임
        System.out.println(b);  // OK
    } // ── 블록 B 끝 → b 사라짐

    System.out.println(b); // 에러: b는 이미 없음
} // ── 블록 A 끝 → a 사라짐
```

## 4. 변수 종류

**클래스 변수 (static 변수)**
- 클래스 영역에서 타입 앞에 `static`이 붙은 변수
- 여러 객체가 공유하는 변수, 모든 객체에서 공통으로 쓸 값이 필요할 때 정의
- 객체 생성 없이 `클래스명.변수명`으로 바로 접근 가능
- 프로그램 시작 시 생성, 종료 시 소멸

**인스턴스 변수 (instance 변수)**
- 클래스 영역에서 `static` 없이 선언한 변수
- 객체마다 따로 생기는 변수, 객체별로 다른 값을 저장할 때 정의
- 객체 생성 후 `참조변수명.변수명`으로 접근
- 값을 넣지 않으면 기본값 자동 저장 (0, false, null)

**지역 변수 (local 변수)**
- 메서드나 블록(`if`, `for` 등) 안에서 선언한 변수 (매개변수 포함)
- 선언된 블록이 끝나면 소멸
- 기본값 없음, 초기화 후에만 사용 가능

|구분|지역 변수|인스턴스 변수|static 변수|
|---|---|---|---|
|**선언 위치**|메서드, 블록 안|클래스 안, 메서드 밖|클래스 안 + `static`|
|**저장 위치**|스택|힙 (객체 안)|메서드 영역|
|**생성 시점**|변수 선언 시|`new`로 객체 생성 시|클래스 로드 시|
|**소멸 시점**|블록 종료 시|객체가 GC될 때|프로그램 종료 시|
|**기본값**|없음 (직접 초기화 필수)|있음 (0, false, null)|있음 (0, false, null)|
|**개수**|실행할 때마다 새로 생성|객체마다 1개|1개 (모든 객체가 공유)|
|**접근 방법**|변수명|`객체.변수명`|`클래스명.변수명`|
|**비유**|연습장|이름표|교실 칠판|
