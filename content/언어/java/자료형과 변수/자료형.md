#java

## 1. 자료형 종류

1. **문자열** (String)
2. **숫자 자료형** (int, long, double...)
3. **불리언 자료형** (boolean)

## 2. 자료형 구분

- **기본 자료형**
	- 실제 데이터 값을 저장
	- int, long, float, double, boolean, char
- **참조 자료형**
	- 데이터가 저장된 메모리 주소 값을 저장
	- 클래스, 인터페이스, 배열, 열거형, String

|자료형|데이터|크기 (byte)|표현 범위|
|---|---|---|---|
|**int**|정수|4|-2,147,483,648 ~ 2,147,483,647|
|**long**|정수|8|-9,223,372,036,854,775,808 ~ 9,223,372,036,854,775,807|
|**float**|실수|4|(정밀도 기준) 6~7 자리|
|**double**|실수|8|(정밀도 기준) 15 자리|
|**boolean**|참 / 거짓|1|true, false|
|**char**|문자|2|하나의 문자|

## 3. 리터럴

^ebd636

- 코드에 직접 적은 값 그 자체
- 정수 리터럴은 기본 `int`, 실수 리터럴은 기본 `double`

**접미사**: 리터럴 뒤에 붙여 타입 지정
```java
long big = 3000000000L; // L 없으면 int로 인식되어 에러 
float f = 3.14f; // f 없으면 double로 인식되어 에러 ​```
```

**따옴표**: 문자와 문자열 구분
```java
char c = 'A'; // 작은따옴표, 문자 하나
String s = "A"; // 큰따옴표, 문자열 (참조 자료형)
```

## 4. 주의할 점

- **실수 오차**: `0.1 + 0.2`의 결과는 `0.30000000000000004` -> 정확한 계산에는 `BigDecimal` 사용
- **오버플로우**: 범위를 넘으면 에러 없이 반대쪽 끝으로 이동
```java
int max = 2147483647;
System.out.println(max + 1); // -2147483648
```
