#java

> 조건에 따른 분기

## 1. if
- 조건이 true일 때만 실행
​```java
if (score >= 60) {
    System.out.println("합격");
}
​```

## 2. if - else
- 조건이 true면 if 블록, false면 else 블록 실행
​```java
if (score >= 60) {
    System.out.println("합격");
} else {
    System.out.println("불합격");
}
​```

## 3. else if
- 여러 조건을 위에서부터 차례로 검사, 처음 true인 블록 하나만 실행
​```java
if (score >= 90) {
    System.out.println("A");
} else if (score >= 80) {
    System.out.println("B");
} else {
    System.out.println("C");
}
​```

## 4. switch
- 하나의 값을 여러 경우(case)와 비교
- `break` 없으면 아래 case까지 계속 실행
- `default`: 일치하는 case가 없을 때 실행
```java
java
switch (grade) {
    case 'A':
        System.out.println("최고");
        break;
    case 'B':
        System.out.println("좋음");
        break;
    default:
        System.out.println("노력");
}
```

## 5. 삼항 연산자
- 간단한 if - else를 한 줄로 작성
```java
String result = (score >= 60) ? "합격" : "불합격";
```
