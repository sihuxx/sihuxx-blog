#java

> 같은 코드를 여러 번 실행하는 문법

## 1. for
- 형태: `for (초기값; 조건; 증감) { }`
​```
```java
for (int i = 0; i < 3; i++) {
    System.out.println(i);  // 0, 1, 2
}
```

## 2. while
- 조건이 true인 동안 반복
```java
int i = 0;
while (i < 3) {
    System.out.println(i);  // 0, 1, 2
    i++;
}
```

## 3. do - while
- 일단 한 번 실행 후 조건 검사 → 조건이 false여도 최소 1번 실행
​```
```java
int i = 5;
do {
    System.out.println(i);  // 5 (1번 실행)
    i++;
} while (i < 3);
```

## 4. 2중 반복문
- 반복문 안의 반복문, 바깥 1번 돌 때 안쪽은 전체 반복
```java
for (int i = 2; i <= 3; i++) {
    for (int j = 1; j <= 2; j++) {
        System.out.println(i + " x " + j + " = " + (i * j));
    }
}
```
​
## 5. break / continue
- `break`: 반복문 즉시 종료
- `continue`: 이번 반복만 건너뛰고 다음 반복으로 이동
```java
for (int i = 0; i < 5; i++) {
    if (i == 1) continue;  // 1 건너뜀
    if (i == 3) break;     // 3에서 종료
    System.out.println(i); // 0, 2
}
```
