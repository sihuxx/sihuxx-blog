### 상수 & 변수
변수 혹은 상수 선언 시 `:`를 사용하여 타입 지정 가능

```typescript
let age: number = 25;
age = 26;

const name: string = "sihu";
name = "siho"; // => ❌ 재할당 X
```

### 타입
`number` 타입에는 숫자만, `String` 타입에는 문자만
각각 타입에 맞는 값을 넣어야 함

```typescript
let score: number = 90;
score = 95;
score = "95" // => ❌ 숫자형이 아닌 문자형이라 에러;

let student: string;
student = "sihu";
```

### 타입 추론
`:`으로 타입을 지정해주지 않아도 타입 추론으로 변수에 할당된 값으로 타입을 자체적으로 판단하여 처음 지정해준 값의 타입과 다른 타입의 값이 들어오지 못하게 함

```typescript
let number = 90; // Number 
number = 95;
number = "95"; // => ❌ 위에서 선언한 number 변수에 자료형은 명시되어 있지 않지만 number 타입의 값이 할당되었기 때문에 number의 자료형이 number로 인식하게 됨.
// 즉 해당 변수의 값을 같은 number 타입으로 할당하는 건 O, 다른 자료형의 값을 할당하는 건 X

let number2; // 이 때 number2의 값은 undefined, 타입은 any (어떤 값이든 허용하는 느슨한 타입)
// any 타입은 타입 검사를 무력화 시킴 => 타입스크립트 사용 의미 상실
number2 = 95;
number2 = "95";
```

### BigInt
number 타입으로 표현 불가한 큰 수를 다룰 때 사용하는 자료형
숫자 끝에 n을 붙이거나 BigInt() 함수에 문자열을 인자로 전달하여 BigInt 값을 생성함

BigInt를 작은 수와 연산하면 에러가 발생하기에 BigInt를 작은 수와 연산하려면 작은 수도 BigInt로 만들어줘야함

```typescript
const bigInt = 1234567892345678934567n; // 숫자 끝에 n을 붙이거나
const bigInt2 = BigInt("1234567892345678934567"); // BigInt 함수에 문자열을 인자로 전달하여 BigInt 값 생성

// const wrong = bigInt + 3; => bigInt를 작은 수와 연산하면 에러 발생
const wrong = bigInt + 3n; // bigInt를 작은 수와 연산하려면 작은 수도 BigInt로 만들어줘야함
```
