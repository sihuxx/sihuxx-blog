### 01 typescript란
JavaScript의 모든 기능을 포함하면서, 정적 타입을 지원하는 언어
런타임에 오류를 발견하는 JavaScript의 단점을 보완하여, **컴파일 타임(작성 단계)**에 에러를 잡을 수 있음

### 02 typescript VS javascript

|특징|typescript|javascript|
|------|---|---|
|장점|코드 실행 전 오류 사전 감지, 오류 발생을 대폭 감소시킴으로서 협업에 용이|소규모 프로젝트에 빠르게 적용 가능, 진입 장벽 낮음, 타입 강제 없이 자유로운 코딩 가능|
|차이점|개발 도중에 에러를 확인할 수 있음 (컴파일 O)|런타임 할 때가 되서야 에러를 발견할 수 있음 (컴파일 X)|

### 03 환경설정
1. **설치** `npm install -g typescript`
2. **초기화** `tsc --init`
3. **컴파일** `tsc index.ts` -> `index.js` 생성

### 03-1 nodemon 
1. **설치** `npm i -g nodemon` -> 파일의 변경을 감지하여 코드 실행 등의 작업 자동으로 진행해줌
2. **설정** `nodemon --watch "src/**/*.ts" --exec "ts-node" src/index.ts`
