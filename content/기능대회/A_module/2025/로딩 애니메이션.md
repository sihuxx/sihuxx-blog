## CSS

```css
.loading {
  width: 100vw;
  height: 100vh;
  position: fixed;
  background-color: rgba(0, 0, 0, 0.6);
  z-index: 10000;
  display: flex;
  justify-content: center;
  align-items: center;
  animation: loading 3s forwards step-end;

  & .ring {
    width: 80px;
    height: 80px;
    border-radius: 50%;
    border: 15px solid white;
    border-right: 15px solid rgb(148, 221, 255);
    opacity: 0.8;
    animation: ring 3s forwards;
  }
}

@keyframes loading {
  0% {
    opacity: 1;
    pointer-events: unset;
  }
  100% {
    opacity: 0;
    pointer-events: none;
  }
}

@keyframes ring {
  0% {
    transform: rotate(0deg);
  }
  100% {
    transform: rotate(540deg);
  }
}
```
