# 공통 모듈 (Router, DB, Lib)

#기능대회

## 1. 라우터 (Router)

### 로직

- **`path` 메서드**: URL의 `{id}` 부분을 정규표현식 `([^\/]+)`으로 변환해 라우팅 테이블 `$routes`에 저장함
- **`handleRequest` 메서드**: 요청 메서드(GET/POST)와 URI를 분석해 등록된 정규식과 매칭하고, 파라미터를 추출해 핸들러를 실행함(`call_user_func_array`)
- **매칭 실패 시**: `move("/")`로 메인 페이지 이동
- **`get` / `post` 함수**: `router::path`를 간편하게 호출하는 래퍼(Wrapper) 함수

### 사용 함수

- **`preg_replace`**: 정규식 패턴과 일치하는 부분을 다른 문자열로 치환 (URL의 `{변수}`를 정규식으로 변경)
- **`preg_match`**: 문자열이 정규식과 일치하는지 검사하고, 결과를 배열 `$matches`에 담음
- **`array_shift`**: 배열 맨 앞 요소를 제거하고 그 값을 반환 (불필요한 전체 매칭 문자열 제거용)
- **`call_user_func_array`**: 파라미터를 배열로 전달해 함수(콜백)를 실행

```php
<?php

class router {
  static $routes = [];
  static function path($reqM, $uri, $hdl) {
    $uri = preg_replace('#\{(.*?)\}#', '([^\/]+)', $uri);
    return self::$routes[] = [$reqM, "#^$uri$#", $hdl];
  }

  static function handleRequest() {
    $REQUEST_METHOD = $_SERVER["REQUEST_METHOD"];
    $path = parse_url($_SERVER["REQUEST_URI"], PHP_URL_PATH);

    foreach(self::$routes as $r) {
      [$reqM, $uri, $hdl] = $r;
      if($reqM !== $REQUEST_METHOD) continue;
      if(preg_match($uri, $path, $matches)) {
        array_shift($matches);
        call_user_func_array($hdl, $matches);
        return "suc";
      }
    }
    move("/");
  }
}

function get($uri, $hdl) {
  router::path("GET", $uri, $hdl);
}

function post($uri, $hdl) {
  router::path("POST", $uri, $hdl);
}
```

## 2. DB 연결 (DB)

### 로직

- **지연 연결 (Lazy Loading)**: `__callStatic`으로 DB 메서드가 실제 호출될 때 `PDO` 객체를 생성함
- **매직 메서드 활용**: `exec`, `fetch`, `fetchAll` 호출을 가로채 `match` 문으로 알맞은 PDO 메서드를 실행함
- **PDO 옵션**
  - `[19 => 5]`: `FETCH_OBJ` (객체로 반환)
  - `[3 => 2]`: `ERRMODE_EXCEPTION` (에러 시 예외 발생)

```php
<?php

class DB
{
  static $db = null;

  static function __callStatic($name, $args)
  {
    // DB 연결 (없을 경우에만 생성)
    self::$db ??= new PDO("mysql:host=localhost;dbname=library;charset=utf8mb4", "root", "", [19 => 5, 3 => 2]);

    // 메서드명에 따른 분기 처리
    return match($name) {
      "exec" => self::$db->exec($args[0]),                  // INSERT, UPDATE, DELETE
      "fetch" => self::$db->query($args[0])->fetch(),       // SELECT (단일 행)
      "fetchAll" => self::$db->query($args[0])->fetchAll(), // SELECT (전체 행)
    };
  }
}
```

## 3. 라이브러리 (Lib)

### 로직

- **`move` / `back`**: 페이지 이동(`location.href`) 또는 뒤로 가기(`history.back`) 수행, 알림창(`alert`)은 선택 사항
- **`views`**: 헤더(header), 본문(page), 푸터(footer) 순으로 파일을 불러와 화면 렌더링
- **`hashPsw`**: `random_bytes`로 만든 솔트(Salt)와 비밀번호를 결합해 SHA-256 해싱, `[해시값, 솔트]` 배열 반환

```php
<?php

// 페이지 이동 (알림 옵션 포함)
function move($uri, $msg = false)
{
  if($msg) {
    echo "<script>alert('$msg')</script>";
  }
  echo "<script>location.href = '$uri'</script>";
}

// 뷰 렌더링 (헤더/푸터 포함)
function views($page)
{
  require_once '../views/template/header.php';
  require_once "../views/$page.php";
  require_once '../views/template/footer.php';
}

// 단순 알림창
function alert($msg) {
  echo "<script>alert('$msg')</script>";
}

// 뒤로 가기 (알림 옵션 포함)
function back($msg = false)
{
  if($msg) {
    echo "<script>alert('$msg')</script>";
  }
  echo "<script>history.back()</script>";
}

// 비밀번호 해싱 (SHA256 + Salt)
function hashPsw($psw)
{
  $salt = bin2hex(random_bytes(32));
  $h_psw = hash("sha256", $psw . $salt);
  return [$h_psw, $salt]; // [해시값, 솔트] 반환
}
```
