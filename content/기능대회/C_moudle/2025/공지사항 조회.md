# 공지사항 조회

#기능대회

## 1. Frontend (PHP/HTML)

- **데이터 주입**: PHP의 `json_encode`로 서버 데이터를 JS 변수로 변환
- **컨트롤 패널**
  - 페이지 이동: 좌/우 화살표 아이콘
  - 정렬/필터: `onclick="sort()"` 함수 하나로 정렬(ASC/DESC)과 유형 필터(일반/이벤트)를 모두 제어
- **데이터 테이블**: `<tbody>`를 비워 두고 JS가 데이터를 렌더링

```html
<article class="content02">
  <h1>공지사항</h1>

  <div class="notice-control">
    <a class="left"><i class="fa fa-arrow-left fa-1x"></i></a>
    <a class="right"><i class="fa fa-arrow-right fa-1x"></i></a>
  </div>

  <div class="notice-align">
    <div class="btn-box">
      <a onclick="sort('sort', 'asc')">ASC</a>
      <a onclick="sort('sort', 'desc')">DESC</a>
    </div>
    <div class="btn-box">
      <a onclick="sort('filter', '일반')">일반</a>
      <a onclick="sort('filter', '이벤트')">이벤트</a>
    </div>
  </div>

  <table class="notice-content">
    <thead>
      <th>유형</th>
      <th>제목</th>
      <th>공지일자</th>
    </thead>
    <tbody>
    </tbody>
  </table>
</article>
```

## 2. Frontend (JavaScript)

- **데이터 초기화**: PHP에서 받은 원본 데이터(`noticeList`)와 필터링/정렬용 사본(`curr`)을 분리해 관리
- **렌더링 (`renderNotices`)**: `curr`를 `slice`로 페이지당 개수(`limit`)만큼 잘라 `innerHTML`로 테이블에 출력
- **통합 제어 (`sort`)**
  - **Filter**: 원본 데이터에서 특정 유형만 추출해 `curr` 갱신
  - **Sort**: 현재 `curr`를 날짜(`localeCompare`) 기준으로 정렬
  - 변경 시 페이지를 0으로 초기화하고 화면 갱신
- **페이지네이션 (`changePage`)**: 현재 데이터 개수로 최대 페이지를 동적으로 계산하고, 인덱스를 변경해 즉시 렌더링

```javascript
// 1. 데이터 및 상태 변수 초기화
const noticeList = <?= json_encode($notices) ?>; // PHP 데이터 수신 (불변 원본)
const tableBody = document.querySelector('.notice-content tbody');
const limit = 5; // 한 페이지당 표시할 개수

let pageIndex = 0;          // 현재 페이지
let curr = [...noticeList]; // 출력용 데이터 사본 (필터/정렬 적용 대상)

// 2. 화면 렌더링 함수
function renderNotices() {
  // 현재 페이지에 해당하는 데이터만 잘라서(slice) HTML로 변환(map -> join)
  tableBody.innerHTML = curr
    .slice(pageIndex * limit, (pageIndex + 1) * limit)
    .map(n => `<tr>
      <td>${n.type}</td>
      <td>${n.title}</td>
      <td>${n.date}</td>
    </tr>`).join('');
}

// 3. 정렬 및 필터 통합 함수
function sort(mode, val) {
  pageIndex = 0; // 목록이 바뀌므로 1페이지로 초기화

  if (mode === 'filter') {
    // 유형 필터링 (삼항 연산자 활용)
    // 주의: '전체' 보기 기능이 필요하면 조건 추가 필요
    curr = val == '일반' ? noticeList.filter(n => n.type == '일반') : noticeList.filter(n => n.type == '이벤트');
  } else {
    // 날짜 기준 정렬 (문자열 비교)
    curr.sort((a, b) => val === 'asc' ? a.date.localeCompare(b.date) : b.date.localeCompare(a.date));
  }
  renderNotices(); // 변경된 데이터로 화면 갱신
}

// 4. 페이지 이동 함수
function changePage(d) {
  // 현재 필터링된 데이터 개수 기준으로 최대 페이지 계산
  const maxPage = Math.ceil(curr.length / limit) - 1;

  // 이동 불가능한 범위(첫 페이지 이전, 마지막 페이지 이후) 체크
  if ((d < 0 && pageIndex <= 0) || (d > 0 && pageIndex >= maxPage)) return;

  pageIndex += d;  // 페이지 인덱스 변경
  renderNotices(); // 화면 즉시 갱신 (애니메이션 없음)
}

// 5. 이벤트 리스너 바인딩 및 초기 실행
document.querySelector('.right').onclick = () => changePage(1);
document.querySelector('.left').onclick = () => changePage(-1);

renderNotices(); // 초기 로드 시 실행
```
