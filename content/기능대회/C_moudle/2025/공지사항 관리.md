# 공지사항 관리 (Notice Management)

#기능대회

## 1. Frontend (화면 구성)

### `noticeAdd.php` (공지사항 등록 페이지)

- 공지사항 유형(일반/이벤트)을 선택하는 `<select>` 제공
- 제목 입력 폼 제공
- 입력 정보는 `noticeAddAction.php`로 `POST` 전송

```php
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>공지사항 추가</title>
  <link rel="stylesheet" href="./style/style.css">
</head>
<body>
  <?php require_once './header.php'; ?>
  <main>
    <h1>공지사항 추가</h1>
    <form action="./noticeAddAction.php" method="post" class="form-content">
      <select name="type" required>
        <option value="일반">일반</option>
        <option value="이벤트">이벤트</option>
      </select>

      <div>
        <label for="title">제목</label>
        <input type="text" placeholder="제목" name="title" id="title" required>
      </div>

      <button>추가</button>
    </form>
  </main>
</body>
</html>
```

### `noticeEdit.php` (공지사항 수정 페이지)

- URL 파라미터 `idx`로 수정할 공지사항 데이터를 DB에서 조회
- 조회한 `$notice`로 기존 값(`value`)과 선택 옵션(`selected`)을 폼에 채움
- 수정 정보는 `noticeEditAction.php`로 전송

```php
<?php
require_once './header.php';
$idx = $_GET["idx"];
// 기존 데이터 조회
$notice = db::fetch("select * from notice where idx = '$idx'");
?>
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>공지사항 수정</title>
  <link rel="stylesheet" href="./style/style.css">
</head>
<body>
  <main>
    <h1>공지사항 편집</h1>
    <form action="./noticeEditAction.php?idx=<?=$idx?>" method="post" class="form-content">
      <select name="type" required>
        <option value="일반" <?= $notice->type == "일반" ? 'selected' : '' ?>>일반</option>
        <option value="이벤트" <?= $notice->type == "이벤트" ? 'selected' : '' ?>>이벤트</option>
      </select>

      <div>
        <label for="title">제목</label>
        <input type="text" placeholder="제목" name="title" id="title" value="<?=$notice->title?>" required>
      </div>

      <button>편집</button>
    </form>
  </main>
</body>
</html>
```

### `noticeAdmin.php` (공지사항 관리 목록)

- DB에서 모든 공지사항(`select * from notice`) 조회
- `foreach`로 테이블 행(`tr`)을 생성해 데이터 출력
- 각 행에 수정/삭제 버튼 배치

```php
<main class="admin-content">
  <h1>공지사항 관리</h1>
  <a href="./noticeAdd.php" class="add-btn">공지사항 추가</a>

  <table class="notice-content">
    <thead>
      <th>유형</th>
      <th>제목</th>
      <th>날짜</th>
      <th>관리</th>
    </thead>
    <tbody>
      <?php foreach($notices as $noti) { ?>
      <tr>
        <td><?= $noti->type ?></td>
        <td><?= $noti->title ?></td>
        <td><?= $noti->date ?></td>
        <td>
          <a href="./noticeEdit.php?idx=<?=$noti->idx?>">수정</a>
          <a href="./noticeDeleteAction.php?idx=<?=$noti->idx?>">삭제</a>
        </td>
      </tr>
      <?php } ?>
    </tbody>
  </table>
</main>
```

## 2. Backend (데이터 처리)

### `noticeAddAction.php` (등록 처리)

- 폼 데이터를 받아 DB에 `INSERT`
- 완료 알림 후 관리 페이지로 이동

```php
<?php
require_once './db.php';
require_once './lib.php';

$title = $_POST["title"];
$type = $_POST["type"];

// 데이터 삽입
db::exec("insert into notice(type, title) values('$type', '$title')");

alert("공지사항이 추가되었습니다");
move("./noticeAdmin.php");
```

### `noticeEditAction.php` (수정 처리)

- `idx`와 수정할 데이터를 받아 DB `UPDATE`
- 완료 알림 후 관리 페이지로 이동

```php
<?php
require_once './db.php';
require_once './lib.php';

$idx = $_GET["idx"];
$title = $_POST["title"];
$type = $_POST["type"];

// 데이터 수정
db::exec("update notice set title = '$title', type = '$type' where idx = '$idx'");

alert("공지사항 수정 완료");
move("./noticeAdmin.php");
```

### `noticeDeleteAction.php` (삭제 처리)

- `idx` 파라미터로 해당 레코드를 DB에서 `DELETE`
- 완료 알림 후 관리 페이지로 이동

```php
<?php
require_once './db.php';
require_once './lib.php';

$idx = $_GET["idx"];

// 데이터 삭제
db::exec("delete from notice where idx = '$idx'");

alert("공지사항 삭제 완료");
move('./noticeAdmin.php');
```
