# 회원 관리 (User Management)

#기능대회

## `user_list.php` (회원 목록 페이지)

- **DB 연결**: `DB::fetchAll`로 `user` 테이블의 모든 데이터 조회
- **리스트 출력**: `foreach`로 회원의 아이디와 비밀번호를 리스트로 출력
- **레이아웃**: 상단 헤더(`header.php`)와 하단 푸터(`footer.php`)를 포함해 페이지 구성

```php
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
  <title>Document</title>
</head>

<body>

  <?php require_once "./parts/header.php" ?>

  <main>
    <div class="notice">
      <div class="title">회원관리</div>

      <div class="notice-table">
        <div class="notice-head">
          <p style="width: calc(1400px /2);">아이디</p>
          <p style="width: calc(1400px /2);">비밀번호</p>
        </div>
        <div class="notice-body">
          <?php
          // user 테이블의 모든 정보 조회
          $user = DB::fetchAll("select * from user");

          // 조회된 데이터 반복 출력
          foreach ($user as $value) {
              ?>
            <div class="notice">
              <p style="width: calc(1400px /2);"><?= $value->id ?></p>
              <p style="width: calc(1400px /2);"><?= $value->psw ?></p>
            </div>
          <?php
          }
          ?>
        </div>
      </div>
    </div>
  </main>
  <?php require_once "./parts/footer.php" ?>

  <script src="./js/lib.js"></script>
</body>
</html>
```
