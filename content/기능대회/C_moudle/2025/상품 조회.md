# 상품 조회 페이지 (Product Display)

## 1. 전체 상품 조회 (`sub02.php`)

- **카테고리별 출력**: 사전에 정의한 5개의 카테고리 배열을 순회하며 DB에서 상품 조회
- **정렬**: 가격 내림차순(`ORDER BY price DESC`)
- **가격 표시 로직**: 원가(`price`)와 할인가(`discount`)가 다르면 두 가격을 모두 표시하고, 같으면 할인가만 표시
- **장바구니 담기**: AJAX(`fetch`)로 비동기 추가

```php
<?php
  require_once './header.php';
  $category = ["건강식품", "디지털", "팬시", "향수", "헤어케어"];
?>

<div class="items">
  <?php foreach($category as $cate) {
    $items = db::fetchAll("select * from item where cate = '$cate'  order by price desc");
    foreach($items as $item) { ?>
    <div class="item" data-id="<?=$item->idx?>">
      <div class="img-cover">
        <img src="<?=$item->img?>" alt="<?=$item->title?>">
      </div>
      <div class="item-content">
        <div class="item-name"><?=$item->title?></div>
        <div class="item-price">
          <div class="dis"><?=$item->discount?></div>
          <?php if($item->price != $item->discount) { ?>
          <div class="price"><?=$item->price?></div>
          <?php } ?>
        </div>
      </div>
      <div class="btns">
        <a href="#">구매하기</a>
        <a href="#" class="get">장바구니 담기</a>
      </div>
    </div>
    <?php }
  } ?>
</div>
```

## 2. 인기 상품 조회 (`sub03.php`)

- **인기 상품 필터링**: DB 쿼리에서 `is_popular = 1` 조건으로 인기 상품만 조회
- **UI 요소**: 일반 상품과 달리 이미지 위에 "인기상품" `badge` 표시
- **데이터 없음 처리**: 해당 카테고리에 인기 상품이 있을 때만 섹션 렌더링

```php

 $category = ["건강식품", "디지털", "팬시", "향수", "헤어케어"];
?>

<div class="items">
<?php foreach($category as $cate) {
  $items = db::fetchAll("select * from item where cate = '$cate' and is_popular = '1' order by price desc");

  <div class="item" data-id="<?=$item->idx?>">
    <div class="img-cover">
      <img src="<?=$item->img?>" alt="<?=$item->title?>">
    </div>
    <div class="item-content">
      <div class="item-name"><?=$item->title?></div>
      <div class="item-price">
        <div class="dis"><?=$item->discount?></div>
        <?php if($item->price != $item->discount) { ?>
        <div class="price"><?=$item->price?></div>
        <?php } ?>
      </div>
    </div>
    <div class="btns">
      <a href="#">구매하기</a>
      <a href="#" class="get">장바구니 담기</a>
    </div>
  </div>
  <?php }
} ?>
</div>
```

## 3. 공통 JavaScript

- 페이지 내 모든 '장바구니 담기' 버튼(`.get`)을 선택
- 클릭 시 해당 상품의 고유 ID(`data-id`) 추출
- `fetch` API로 백엔드(`cartAddAction.php`)에 비동기 요청
- 서버 응답 메시지(성공/실패/로그인 필요 등)를 `alert`로 출력

```javascript
const butBtns = document.querySelectorAll(".get");

butBtns.forEach(btn => {
  btn.addEventListener("click", () => {
    // 클릭된 버튼의 부모(.item)에서 data-id 값 추출
    const itemIdx = btn.closest('.item').getAttribute("data-id");

    // 비동기 요청
    fetch(`./cartAddAction.php?idx=${itemIdx}`)
      .then((res) => res.text())
      .then((message) => {
        alert(message); // 결과 알림
      });
  });
});
```
