# 캘린더 (대여 기록 달력)

## 1. PHP: 날짜 계산 및 데이터 조회 (Backend)

캘린더를 그리기 위해 현재 달의 정보와 데이터를 준비하는 단계

### 날짜 변수 설정

```php
$year = isset($_GET['year']) ? $_GET["year"] : date('Y'); // GET 값이 있으면 해당 연도, 없으면 현재 연도
$month = isset($_GET['month']) ? $_GET["month"] : date('m'); // GET 값이 있으면 해당 월, 없으면 현재 월

$date = "$year-$month-01";       // 해당 월의 1일 날짜 생성
$time = strtotime($date);        // 날짜를 타임스탬프로 변환
$start_week = date("w", $time);  // 1일의 요일 (0:일, 1:월 ... 6:토)
// date("w"): 요일 숫자값, 일요일(0) ~ 토요일(6)
$total_day = date("t", $time);   // 해당 월의 총 일수 (28 ~ 31)
// date("t"): 해당 월의 마지막 날
$total_week = ceil(($total_day + $start_week) / 7); // 캘린더에 필요한 총 주(행) 수
```

- **`$start_week`**: 첫 번째 줄에서 1일이 시작되기 전의 빈 칸 수를 채우는 데 필요
- **`$total_week`**: `(총 일수 + 시작 요일 빈 칸) / 7`을 올림(`ceil`)해 필요한 줄(`<tr>`) 수 계산

### 데이터베이스 조회

```php
$users = db::fetchAll("select u.*, ub.*, s.idx, u.idx as user_id from user u
inner join user_book ub on u.idx = ub.user_idx
inner join stores s on s.idx = ub.store_idx
where ub.rental_date like '$year-$month-%' and s.idx = $store_idx
group by u.idx, ub.rental_date");
```

- `$year-$month-%` 패턴으로 해당 연/월에 대여 기록이 있는 유저 데이터 조회
- `store_idx`로 현재 보고 있는 지점의 데이터만 필터링

## 2. HTML/PHP: 캘린더 렌더링 (Frontend)

계산한 변수로 실제 `<table>`을 그리는 단계

### 월 이동 버튼 (네비게이션)

```php
<?php if ($month == 1) { ?>
  <a href="?year=<?= $year - 1 ?>&month=12">&lt;</a> <?php } else { ?>
  <a href="?year=<?= $year ?>&month=<?= $month - 1 ?>">&lt;</a> <?php } ?>

<?php if ($month == 12) { ?>
  <a class="btn white-btn" href="?year=<?= $year + 1 ?>&month=1">&lt;</a>
<?php } else { ?>
  <a class="btn white-btn" href="?year=<?= $year ?>&month=<?= $month + 1 ?>">&gt;</a>
<?php } ?>
```

- 1월(이전) 또는 12월(다음)일 때 연도(`year`)가 바뀌도록 분기

### 날짜 출력 로직 (이중 반복문)

```php
<?php
// $n: 날짜 카운터 (1부터 시작, 출력 후 증가)
// $i: 주(Week) 반복 인덱스
// $total_week: 이 달에 필요한 총 주(행) 개수
for ($n = 1, $i = 0; $i < $total_week; $i++) { ?>
  <tr>
    <?php
    // $k: 요일(Day) 반복 인덱스 (0:일 ~ 6:토)
    for ($k = 0; $k < 7; $k++) { ?>
      <td style="cursor:pointer;">
        <?php
        /*
         * [날짜 출력 핵심 로직]
         * 1. 시작 시점 체크 (($n > 1 || $k >= $start_week))
         *    - $n > 1 : 1일이 이미 지났다면(2일, 3일...) 요일 상관없이 계속 출력
         *    - $k >= $start_week : 첫째 주($i=0)에서 현재 요일($k)이 시작 요일($start_week)에 도달했을 때 출력 시작
         *    => 이미 시작했거나($n>1) 또는 오늘이 1일 요일($k)과 같은가?
         *
         * 2. 종료 시점 체크 ($total_day >= $n)
         *    - 출력하려는 날짜($n)가 이번 달의 총 일수($total_day)를 넘지 않아야 함
         */
        if (($n > 1 || $k >= $start_week) && ($total_day >= $n)) {
          echo $n++; // 현재 날짜($n)를 출력하고 1 증가 (후위 연산자)
        }
        ?>
      </td>
    <?php } ?>
  </tr>
<?php } ?>
```

- **`$n`**: 날짜 카운터 (1부터 시작)
- **핵심 조건문**: 첫째 주(`$i==0`)에는 `$start_week`에 도달하기 전까지 빈 `<td>`를 출력하고, 이후부터 숫자 출력

## 3. JavaScript: 상호작용 및 모달

서버에서 받은 데이터로 대여 기록을 표시하고, 클릭 시 상세 내용을 표시

### 대여 기록 표시 (`rentalDate`)

```javascript
function rentalDate() {
  const rentalDates = userData.map(user => user.rental_date); // 대여 날짜만 추출

  tds.forEach(td => {
    const day = td.textContent.trim();
    if (!day) return; // 빈 칸 건너뜀

    // 'YYYY-MM-DD' 형식으로 변환 (pad 함수로 0 채움)
    const targetDate = `${year}-${pad(month)}-${pad(day)}`;

    if (rentalDates.includes(targetDate)) {
      td.classList.add("is-rental"); // CSS 클래스 추가 (색상 변경 등)
    }
  })
}
```

- PHP에서 넘겨받은 `$users`를 JS 변수 `userData`에 담아 사용
- 달력의 각 날짜(`td`)를 순회하며 대여 기록이 있는 날짜면 `is-rental` 클래스를 추가해 표시

### 클릭 이벤트 및 모달 (`openRental`)

```javascript
function pad(number) {
  return number.toString().padStart(2, '0');
}

function openRental() {
  rentalDate();

  tds.forEach(td => {
    td.addEventListener('click', (event) => {
      // 1. 클릭한 날짜 가져오기
      const day = event.currentTarget.textContent.trim();
      const targetDate = `${year}-${pad(month)}-${pad(day)}`;

      // 2. 해당 날짜의 대여 데이터 필터링
      const filterData = userData.filter(user => user.rental_date == targetDate);

      // 3. 모달 내용 생성 (Template Literal)
      let htmlContent = "";
      if (filterData.length > 0) {
        filterData.forEach(user => {
          htmlContent += `<div>...유저 정보 및 프로필 링크...</div>`;
        });
      } else {
        htmlContent += `<p>대여 기록이 없습니다.</p>`;
      }

      // 4. 모달 표시
      modalContent.innerHTML = htmlContent;
      background.style.display = 'flex'; // 모달 열기
    });
  });
}
```

- 날짜 셀을 클릭하면 `userData`에서 해당 날짜(`targetDate`)의 데이터만 `filter`
- 필터링한 데이터를 HTML 문자열로 만들어 모달 창(`rental-user-modal`)에 넣고 표시
