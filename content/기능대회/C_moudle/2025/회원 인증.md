# 헤더 및 인증 시스템 (Header & Auth)

#기능대회

## 1. 헤더 및 모달 (Frontend)

- **네비게이션**: 로고, 서브 메뉴(소개, 상품, 가맹점, 장바구니)를 포함한 공통 레이아웃
- **사용자 상태 분기**: PHP 세션(`$_SESSION["ss"]`)을 확인해 상태별 UI 렌더링
  - **비로그인**: 로그인/회원가입 버튼 표시 (클릭 시 모달 팝업)
  - **관리자 (`isAd == 1`)**: 관리자 메뉴(공지/상품 관리)와 로그아웃 표시
  - **일반 회원**: 사용자 이름과 로그아웃 표시
- **모달 제어 (JS)**: `display: none/flex` 스타일을 조작해 로그인/회원가입 팝업을 열고 닫음

```php
<header>
  <div class="nav02">
    <?php
      $user = $_SESSION["ss"] ?? null; // 세션에서 유저 정보 가져오기

      // 1. 비로그인 상태
      if ($user === null) {
    ?>
      <a class="loginOpen">로그인</a>
      <a class="regOpen">회원가입</a>

    <?php
      // 2. 관리자 로그인 상태
      } else if ($user->isAd == 1) {
    ?>
      <a href="#">관리자</a>
      <div class="sub">
        <li><a href="../../view/notice/list.php">공지사항 관리</a></li>
        <li><a href="../../view/item/list.php">판매상품 관리</a></li>
      </div>
      <a href="../../action/user/logout.php">로그아웃</a>

    <?php
      // 3. 일반 사용자 로그인 상태
      } else {
    ?>
      <a href="#"><?= $user->id ?>님</a>
      <a href="../../action/user/logout.php">로그아웃</a>
    <?php } ?>
  </div>
</header>

<div class="sign-back-container">
  <div class="login signBox">
    <form action="../../action/user/action.php" method="post">
      <input type="hidden" name="type" value="login">
    </form>
  </div>

  <div class="reg signBox">
    <form action="../../action/user/action.php" method="post">
      <input type="hidden" name="type" value="reg">
    </form>
  </div>
</div>

<script>
  // 모달 제어 스크립트
  const login = document.querySelector(".login");
  const reg = document.querySelector(".reg");
  const back = document.querySelector('.sign-back-container'); // 배경

  // 로그인 버튼 클릭 시
  document.querySelector(".loginOpen").addEventListener("click", () => {
    login.style.display = "flex";
    reg.style.display = 'none';
    back.style.display = 'flex';
  });

  // 회원가입 버튼 클릭 시
  document.querySelector(".regOpen").addEventListener("click", () => {
    reg.style.display = "flex";
    login.style.display = 'none';
    back.style.display = 'flex';
  });

  // 닫기 버튼 로직 생략
</script>
```

## 2. 회원가입 및 로그인 처리 (Backend)

- 파일 하나(`action.php`)에서 `type` 파라미터로 요청을 구분해 처리
- **회원가입 (`type === "reg"`)**
  - 아이디 중복 검사
  - 비밀번호를 **Salt**와 함께 해싱(`hashPsw`)해 저장
- **로그인 (`type === "login"`)**
  - DB에서 해당 ID의 사용자 조회
  - 사용자의 **Salt**를 가져와 입력한 비밀번호와 결합해 해싱
  - 저장된 해시값과 일치하면 세션(`$_SESSION["ss"]`) 생성

```php
<?php
require_once "../../includes/db.php";
require_once "../../includes/lib.php";

$type = $_POST["type"]; // 'reg' or 'login'

if ($type === "reg") {
  // --- 회원가입 로직 ---
  $id = $_POST["id"];

  // 1. 아이디 중복 체크
  if (DB::fetch("SELECT * from user where id = '$id'")) {
    alert("이미 사용중인 아이디입니다");
  } else {
    // 2. 비밀번호 해싱 (Salt 생성 포함)
    [$salt, $h_psw] = hashPsw($_POST["psw"]);

    // 3. DB 저장
    DB::exec("INSERT INTO user(name, id, psw, salt, email) VALUES ('$name','$id','$h_psw','$salt','$email')");
    alert("회원가입 성공");
  }
  move('/'); // 메인으로 이동

} else {
  // --- 로그인 로직 ---
  $id = $_POST["id"];
  $psw = $_POST["psw"];

  // 1. 사용자 존재 확인
  if (!DB::fetch("SELECT * from user where id = '$id'")) {
    alert("존재하지 않는 사용자입니다");
  } else {
    $user = DB::fetch("SELECT * from user where id = '$id'");

    // 2. 비밀번호 검증 (입력값 + DB Salt 해싱 == DB 해시값)
    $input_h_psw = hash("sha256", $psw . $user->salt);

    if ($input_h_psw !== $user->psw) {
      alert("비밀번호가 일치하지 않습니다");
    } else {
      // 3. 세션 생성
      $_SESSION["ss"] = $user;
      alert("로그인 성공");
    }
    move('/');
  }
}
```

## 3. 로그아웃 (Backend)

- `session_destroy()`로 현재 세션 파기
- 메인 페이지(`/`)로 리다이렉트

```php
<?php
require_once "../../includes/db.php";
require_once "../../includes/lib.php";

// 세션 파기
session_destroy();

// 메인으로 이동
move('/');
```
