# 상품 관리 (Product Management)

## 1. Frontend (화면 구성)

### `itemAdd.php` (상품 등록 페이지)

- `<input type="file">`로 상품 이미지를 입력받음
- 드롭다운(`<select>`)으로 카테고리(건강식품, 디지털, 팬시 등) 선택
- 상품명, 설명, 가격을 입력받아 `itemAddAction.php`로 `POST` 전송

```php
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>판매상품 추가</title>
  <link rel="stylesheet" href="./style/style.css">

<body>
  <?php require_once './header.php'?>
  <main class="admin-content">
    <h1>판매상품 추가</h1>
    <form action="./itemAddAction.php" method="post" class="form-content" enctype="multipart/form-data">
      <input type="file" name="file" required>

      <select name="cate" id="" required>
        <option value="건강식품">건강식품</option>
        <option value="디지털">디지털</option>
        <option value="팬시">팬시</option>
        <option value="향수">향수</option>
        <option value="헤어케어">헤어케어</option>
      </select>

      <div>
        <label for="title">상품명</label>
        <input type="text" placeholder="상품명" name="title" id="title" required>
      </div>
      <div>
        <label for="des">상품 설명</label>
        <input type="text" placeholder="상품 설명" name="des" id="des" required>
      </div>
      <div>
        <label for="price">가격</label>
        <input type="number" placeholder="가격" name="price" id="price" required>
      </div>

    </form>
  </main>
</body>
</html>
```

### `itemEdit.php` (상품 수정 페이지)

- URL 파라미터 `idx`로 DB에서 기존 상품 정보를 조회해 폼에 채움(`value`)
- '인기상품' 체크박스(`onChange="isPop()"`)로 할인 옵션(만원, 10%, 30%) UI를 동적으로 표시/숨김
- 기존 카테고리와 할인 유형(`discount_type`)을 확인해 `selected`, `checked` 속성 부여

```php
<?php
require_once './header.php';
$idx = $_GET["idx"];
// 기존 데이터 조회
$item = db::fetch("select * from item where idx = '$idx'");
?>
<form action="./itemEditAction.php?idx=<?=$idx?>" method="post" enctype="multipart/form-data">
  <img src="<?=$item->img?>" alt="<?=$item->title?>">

  <select name="cate" required>
    <option value="건강식품" <?= $item->cate == "건강식품" ? 'selected' : ''?>>건강식품</option>
  </select>

  <div>
    <label for="pop">인기상품</label>
    <input type="checkbox" name="pop" id="pop" value="yes" onChange="isPop()" <?=$item->is_popular == "1" ? "checked" : ''?>>
  </div>

  <div class="sale-box"></div>

  <button>상품 수정</button>
</form>

<script>
  // 인기상품 체크 여부에 따라 할인 옵션 UI 렌더링
  function isPop() {
    const checkBox = document.querySelector("#pop");
    const saleBox = document.querySelector(".sale-box");

    if(checkBox.checked) {
      // 할인 옵션 HTML 삽입 (기존 값 유지)
      saleBox.innerHTML = `
        <div>
           <label for="1">만원 할인</label>
           <input type="radio" name="sale" value="1" id="1" <?=$item->discount_type == "1" ? "checked" : ''?>>
        </div>
        `
    } else {
      saleBox.innerHTML = '' // UI 초기화
    }
  }
  isPop(); // 초기 실행
</script>
```

### `itemAdmin.php` (상품 관리 목록)

- 카테고리 배열(`$category`)을 순회하며 해당 카테고리 상품을 가격 내림차순으로 조회
- 각 상품 카드에 수정(`itemEdit.php`), 삭제(`itemDeleteAction.php`) 링크 제공
- 할인가와 원래 가격이 다르면 두 가격을 모두 표시

```php
<main class="admin-content">
  <h1>판매상품 관리</h1>
  <a href="./itemAdd.php" class="add-btn">판매상품 추가</a>

  <div class="items">
    <?php foreach($category as $cate) {
      // 카테고리별 상품 조회
      $items = db::fetchAll("select * from item where cate = '$cate' order by price desc");
      foreach($items as $item) { ?>
        <div class="item" data-id="<?=$item->idx?>">
          <div class="img-cover"><img src="<?=$item->img?>"></div>
          <div class="item-content">
             <div class="item-name"><?=$item->title?></div>
             <div class="item-price">
                <div class="dis"><?=$item->discount?></div>
                <?php if($item->price != $item->discount) { ?>
                  <div class="price"><?=$item->price?></div>
                <?php } ?>
             </div>
          </div>
          <div class="btns">
              <a href="./itemEdit.php?idx=<?=$item->idx?>">수정</a>
              <a href="./itemDeleteAction.php?idx=<?=$item->idx?>">삭제</a>
          </div>
        </div>
      <?php }
    } ?>
  </div>
</main>
```

## 2. Backend (데이터 처리)

### `itemAddAction.php` (등록 처리)

- `move_uploaded_file`로 이미지를 서버에 저장
- 성공하면 `INSERT` 쿼리로 상품 정보 저장 (초기 `discount`는 `price`와 동일)

```php
<?php
// ... 데이터 수신 생략 ...
$file = $_FILES["file"];
$path = './images/items/' . $file['name'];

if(move_uploaded_file($file["tmp_name"], $path)) {
  // DB 삽입
  db::exec("insert into item(title, des, price, discount, cate, img) values('$title', '$des', '$price', '$price', '$cate', '$path')");
  alert("상품 추가 성공");
  move("./itemAdmin.php");
} else {
  alert("상품 추가 실패");
  back();
}
```

### `itemEditAction.php` (수정 처리)

- 인기상품(`pop`) 여부와 할인 타입(`sale`)에 따라 할인가(`discount`) 계산 (만원 차감, 10% 할인, 30% 할인)
- 계산한 할인가, 할인 타입(`discount_type`), 인기상품 플래그(`is_popular`)를 함께 `UPDATE`
- 인기상품이 아니면 원가 그대로 저장하고 플래그 해제

```php
<?php
// ... 변수 할당 생략 ...
$popular = $_POST["pop"] ?? "";
$sale = $_POST["sale"];

if(move_uploaded_file($file["tmp_name"], $path)) {
  if ($popular == "yes") {
    // 할인 로직 계산
    if ($sale == "1") {
      $dis1 = $price - 10000;
      db::exec("update item set ... discount = '$dis1', is_popular = '1', discount_type = '1' ...");
    } else if ($sale == "2") {
      $dis2 = $price * 0.9;
      // ... 10% 할인 업데이트 ...
    } else {
      $dis3 = $price * 0.7;
      // ... 30% 할인 업데이트 ...
    }
    alert("상품 수정 완료");
  } else {
    // 인기상품 해제 (할인가 = 원가)
    db::exec("update item set ... discount = '$price', is_popular = '0', discount_type = '0' ...");
    alert("상품 수정 완료");
  }
  move("./itemAdmin.php");
}
```

### `itemDeleteAction.php` (삭제 처리)

- `idx` 파라미터로 DB에서 해당 상품 레코드 삭제

```php
<?php
require_once './db.php';
require_once './lib.php';

$idx = $_GET["idx"];
db::exec("delete from item where idx = '$idx'"); // 삭제 실행

alert("상품 삭제 완료");
move('./itemAdmin.php');
```
