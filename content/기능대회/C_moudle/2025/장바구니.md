# 장바구니 시스템 (Shopping Cart)

## 1. 장바구니 담기 (Frontend Script)

- 페이지 내 모든 '장바구니 담기' 버튼(`.get`)을 선택
- 클릭 시 해당 상품의 고유 ID(`data-id`) 추출
- `fetch` API로 백엔드(`cartAddAction.php`)에 비동기 요청
- 서버 응답 메시지(성공/실패/로그인 필요 등)를 `alert`로 출력

```javascript
const butBtns = document.querySelectorAll(".get");

butBtns.forEach(btn => {
  btn.addEventListener("click", () => {
    // 클릭된 버튼의 부모(.item)에서 data-id 값 추출
    const itemIdx = btn.closest('.item').getAttribute("data-id");

    // 비동기 요청
    fetch(`./cartAddAction.php?idx=${itemIdx}`)
      .then((res) => res.text())
      .then((message) => {
        alert(message); // 결과 알림
      });
  });
});
```

## 2. 장바구니 담기 액션 (Backend PHP)

- 세션에서 로그인한 사용자 ID 확인
- 로그인 상태이면 이미 장바구니에 해당 상품이 있는지 확인
  - **있으면**: 수량(`count`)을 1 증가시키는 `UPDATE`
  - **없으면**: 새 행을 추가하는 `INSERT`
- 비로그인 상태이면 로그인 요청 메시지 반환

```php
<?php
require_once "../../includes/db.php";   // DB 연결
require_once "../../includes/lib.php";  // 라이브러리 연결

$userId = $_SESSION["ss"]->id ?? false; // 세션에서 유저 ID 가져오기 (없으면 false)
$itemId = $_GET["idx"];                 // URL 파라미터로 상품 ID 받기

if ($userId) {
  // 이미 장바구니에 담긴 상품인지 확인
  if (DB::fetch("select * from cart where itemId = $itemId and userId = '$userId' ")) {
    // 이미 존재하면 수량(count)만 +1 업데이트
    DB::exec("UPDATE cart SET count= count +1 WHERE itemId = $itemId and userId = '$userId'");
  } else {
    // 존재하지 않으면 신규 추가 (기본 수량은 DB 디폴트값)
    DB::exec("INSERT INTO cart(userId, itemId) VALUES ('$userId','$itemId')");
  }
  alert('장바구니에 추가되었습니다'); // 클라이언트로 성공 메시지 전송
  back();
} else {
  alert("로그인 후 이용할 수 있는 기능입니다");
  back(); // 비로그인 시 메시지 전송
}
```

## 3. 장바구니 수량 변경 액션 (Backend PHP)

- **데이터 수신**: URL 파라미터(`GET`)로 상품 번호(`itemId`)와 변경할 수량(`count`)을 받고, 세션에서 로그인 유저 ID 확인
- **로그인 검증**: `userId`가 있어야 이용 가능
- **DB 업데이트**: `UPDATE`로 해당 유저의 장바구니(`cart`)에서 특정 상품의 수량 수정
- **페이지 이동**: 처리 후 `move`로 장바구니 페이지(`sub04.php`)로 리다이렉트

```php
<?php

require_once './db.php';  // DB 연결 설정 파일 로드
require_once './lib.php'; // 공통 함수 라이브러리 로드 (move, alert, back 등)

// 1. GET 파라미터 및 세션 데이터 수신
$itemId = $_GET["itemId"]; // 변경할 상품의 고유 ID
$count = $_GET["count"];   // 변경된 수량 값
$userId = $_SESSION["ss"]->id ?? false; // 로그인 세션 확인 (없으면 false)

// 2. 로그인 상태 확인
if($userId) {
  // 3. DB 업데이트 (해당 유저의 특정 상품 수량 변경)
  db::exec("UPDATE cart SET count = '$count' WHERE itemId = '$itemId' AND userId = '$userId'");

  // 4. 장바구니 페이지로 이동 (화면 갱신)
  move('./sub04.php');
} else {
  // 비로그인 상태 예외 처리
  alert("로그인 후 이용해주세요");
  back(); // 이전 페이지로 복귀
}
```

## 4. 장바구니 페이지 (Frontend PHP)

- 로그인 여부로 분기
- **로그인 시**: `item`과 `cart` 테이블을 `JOIN`해 현재 사용자의 장바구니 목록 조회
- 조회된 상품이 있으면 반복문으로 이미지, 정보, 가격, 수량 조절(input) 렌더링
- **비로그인 시**: 로그인 유도 문구 표시
- 하단에 총 결제 금액과 구매 버튼 배치

```php
<main>
  <?php
     require_once './header.php';
     $userId = $_SESSION["ss"]->id ?? false;
    if($userId) {
    $items = DB::fetchAll("select i.*, c.count from item i join cart c on i.idx = itemId and c.userId = '$userId'");
    ?>
  <h1>장바구니</h1>
  <div class="items">
    <?php if(count($items) > 0) {
                foreach($items as $item) { ?>
    <div class="item" data-id="<?=$item->idx?>">
      <div class="img-cover">
        <img src="<?=$item->img?>" alt="<?=$item->title?>">
      </div>
      <div class="item-content">
        <div class="item-name"><?=$item->title?></div>
        <div class="item-price">
          <div class="dis"><?=$item->discount?></div>
          <?php if($item->price != $item->discount) { ?>
          <div class="price"><?=$item->price?></div>
          <?php } ?>
        </div>
        <div class="count">
          <input type="number" value="<?= $item->count ?>" min="1" onchange="updateDB(<?=$item->idx?>, this.value)" />
          <div>총: <span>
              <?= $item->discount * $item->count?>
            </span> 원</div>
        </div>
      </div>
    </div>
    <?php } ?>
  </div>
  <?php } else { ?>
  <p class="cart-box">장바구니가 비어있습니다</p>
  <?php }
} else { ?>
  <p class="cart-box">로그인 후 이용해주세요</p>
  <?php }?>
  <div class="total-check">
    <div class="total-cost">총 가격:<span></span>원</div>
    <a href="#">구매하기</a>
  </div>
</main>
```

## 5. 가격 실시간 계산 및 DB 업데이트 (Frontend JS)

- **DB 업데이트**: `location.href`로 페이지를 이동(새로고침)시키며 GET 파라미터로 수정 데이터 전송
- **전체 순회**: `querySelectorAll`로 모든 상품 요소(`.item`)를 선택해 `forEach` 실행
- **수치 변환**: 화면의 가격 텍스트와 `input`의 수량을 `parseInt`로 정수 변환
- **총액 계산**: 상품별 `단가 * 수량`을 누적해 최종 결제 금액(`mainTotal`) 산출
- **화면 갱신**: `toLocaleString()`으로 천 단위 콤마 포맷 적용 후 출력

```javascript
// 1. DB 업데이트 함수 (수량 변경 완료 시 호출)
function updateDB(itemId, count) {
  // 페이지를 이동시키며 GET 방식으로 ID와 수량을 서버에 전송 (새로고침됨)
  location.href = `./cartUpdateAction.php?itemId=${itemId}&count=${count}`;
}

// 2. 가격 계산 함수 (화면 갱신용)
function calc() {
  // 장바구니의 모든 상품 요소 선택
  let items = document.querySelectorAll('.item');
  let mainTotal = 0; // 전체 결제 금액

  // 각 상품을 순회하며 계산
  items.forEach((item) => {
    // 가격(.dis) 텍스트를 정수로 변환
    let price = parseInt(item.querySelector(".dis").textContent);

    // 수량 입력창(input) 값을 정수로 변환
    let count = parseInt(item.querySelector('.count > input').value);

    // (단가 * 수량)을 전체 금액에 누적
    let subTotal = price * count;
    mainTotal += subTotal;
  });

  // 최종 금액에 3자리마다 콤마를 찍어(toLocaleString) 표시
  document.querySelector('.total-cost > span').textContent = mainTotal.toLocaleString();
}

// 페이지 로드 직후 최초 1회 가격 계산
calc();
```
