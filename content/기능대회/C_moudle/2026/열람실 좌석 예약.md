# 열람실 좌석 예약 시스템

#기능대회

**초기 예약 데이터 로드**, **마우스 드래그 기반 좌석 선택 UI**, **상태(State) 변화에 따른 화면 렌더링**을 수행하는 스크립트. 코드는 5개 영역으로 구분.

## 1. PHP → JS 데이터 브릿지 (초기화)

서버(PHP)에서 읽은 기존 예약 데이터를 클라이언트(JS)가 쓸 수 있도록 변환해 전달

```php
<?php
// 1) 현재 시간 이후의 유효한 예약 내역만 DB에서 조회
$seatList = db::fetchAll("select * from seats where date > CURDATE() OR end_time > CURTIME() order by create_at, start_time");
$seatData = [];

// 2) 좌석 번호를 Key로, 해당 좌석의 예약 시간들을 배열로 묶음
foreach($seatList as $seat) {
  $seatData[$seat->seat_idx][] = "$seat->date ($seat->start_time ~ $seat->end_time)";
}
?>

<script>
  // 3) PHP 배열($seatData)을 JS 객체(info)로 변환
  const info = <?=json_encode($seatData)?>;
</script>
```

- **핵심 역할**: 빈 좌석 여부와 예약 시간대를 툴팁으로 보여주기 위한 데이터 준비
- **동작 원리**: PHP 연관 배열은 JS에서 그대로 쓸 수 없으므로 `json_encode()`로 `{"1": ["2026-04-06 (10:00 ~ 12:00)"], "5": [...]}` 형태의 JS 객체(JSON)로 변환

## 2. 좌석 DOM 생성 및 기본 설정

75개의 좌석 블록을 그리고, 과거 날짜 예약을 막는 기본 설정

```javascript
const selected = new Set(); // 중복 없는 선택 데이터 저장소
const MAX_SELECT = 4; // 최대 선택 가능 개수
const container = $(".seat-container");

// 1) 75개의 좌석 DOM 동적 생성
for(let i = 1; i <= 75; i++) {
  const seat = newEl("div", {className: "seat", textContent: i});

  // info에 i번 좌석 데이터가 있으면 줄바꿈(\n)으로 이어 툴팁 생성
  seat.title = info[i] ? "최근 예약: \n" + info[i].join("\n") : "예약 내역 없음";
  container.append(seat);
}

// 2) 달력(date) 인풋의 최솟값을 오늘로 강제 설정
const today = new Date().toISOString().split("T")[0]; // "2026-03-28" 추출
$("#dateInput").min = today;
```

- **핵심 역할**: 사용자가 상호작용할 UI 뼈대 생성
- **동작 원리**
  - 배열 대신 **`Set`** 사용이 핵심: 같은 값이 두 번 들어가는 것을 원천 차단하므로 같은 좌석을 여러 번 클릭해도 데이터가 꼬이지 않음
  - `toISOString()`은 현재 시간을 표준 문자열(예: `2026-03-28T11:22:47.000Z`)로 반환하며, `T` 기준으로 `split`해 날짜만 추출해 `<input type="date">`의 `min`에 지정

## 3. 마우스 드래그 선택 로직 (이벤트 리스너)

마우스 버튼을 누른 채 드래그하면 지나가는 좌석이 연속으로 선택/해제되는 로직

```javascript
const seats = $$(".seat"); // 생성된 75개 좌석 요소
let isDragging = false; // 마우스 클릭 상태를 추적하는 플래그(Flag) 변수

// 1) 마우스를 누를 때 (드래그 시작)
container.addEventListener("mousedown", (e) => {
  if(e.target.classList.contains("seat")) {
    isDragging = true; // 드래그 시작
    toggleSeat(e.target); // 마우스를 누른 좌석 토글
  }
});

// 2) 마우스 버튼을 뗄 때 (드래그 종료)
container.addEventListener("mouseup", () => isDragging = false);

// 3) 마우스가 움직이며 다른 요소 위로 올라갈 때
container.addEventListener("mouseover", (e) => {
  // 드래그 중이고, 닿은 곳이 '좌석'일 때만 반응
  if(isDragging && e.target.classList.contains("seat")) {
    toggleSeat(e.target);
  }
});
```

- **핵심 역할**: 하나씩 클릭해야 하는 불편함을 없애고 쭉 긁어서 선택하는 UX 제공
- **동작 원리**
  - 불리언 변수 `isDragging`이 상태를 제어: 누르면(`mousedown`) `true`, 떼면(`mouseup`) 어디서 떼든 `false`
  - `mouseover`는 마우스가 이동할 때마다 수십 번 발생하므로, `isDragging`이 `true`일 때만 `toggleSeat`를 실행하도록 조건을 걸어 드래그 효과 구현

## 4. 상태 관리 및 렌더링 (`toggleSeat`, `render`)

좌석을 클릭/드래그할 때마다 내부 데이터를 갱신하고, 그 데이터로 화면과 Form을 다시 그림

```javascript
// [데이터 업데이트 함수]
function toggleSeat(el) {
  const id = Number(el.textContent); // 클릭된 태그의 텍스트(예: "15")를 숫자로 변환

  // Set에 이미 있으면 삭제(해제), 없으면 추가(선택)
  if(selected.has(id)) {
    selected.delete(id);
  } else {
    // 현재 선택 개수가 MAX(4개) 미만일 때만 추가 허용
    if(selected.size < MAX_SELECT) selected.add(id);
  }
  render(); // 데이터가 변했으므로 화면 갱신
}

// [화면 갱신 함수]
function render() {
  // 1) Set을 일반 배열로 바꿔 숫자 오름차순(1, 2, 3...)으로 정렬
  const arr = [...selected].sort((a, b) => a - b);

  // 2) 75개 좌석을 순회하며, 선택 배열에 자기 번호가 있으면 'selected' 클래스 추가, 없으면 제거
  seats.forEach(s => s.classList.toggle("selected", selected.has(Number(s.textContent))));

  // 3) 안내 텍스트 업데이트 (예: "1, 2, 3번")
  $(".selectedSeats").textContent = arr.length ? arr.join(", ") + "번" : "없음";

  // 4) PHP로 전송될 Form의 숨겨진 input value 업데이트 (예: "1,2,3")
  $("#seatsInput").value = arr.join(",");

  // 5) 선택한 좌석이 0개면 예약 버튼(submit) 비활성화 (disabled = true)
  $(".reserveBtn").disabled = arr.length === 0;
}

render(); // 초기 로드 시 1회 실행하여 버튼 잠금 처리
```

- **핵심 역할**: 사용자 액션 → 내부 데이터 변경 → 화면 UI 및 Form 데이터 동기화 사이클 담당
- **동작 원리**
  - **단방향 데이터 흐름**: `toggleSeat`는 `selected`(Data)만 변경하고, `render`는 `selected`만 보고 화면(View)을 갱신
  - `#seatsInput`에 `arr.join(",")`로 배열을 쉼표 문자열(`"1,2,3"`)로 넣어 두므로, 폼 제출 시 PHP의 `$_POST['seats']`로 전달

## 5. 백엔드 예약 처리 (All or Nothing)

JS가 넘긴 데이터를 받아 안전하게 DB에 저장하는 로직

```php
post("/reserve", function () {
  extract($_POST);
  $user = ss();
  $seatArr = explode(",", $seats); // "1,2,3" 문자열을 [1, 2, 3] 배열로 복구

  if (empty($user)) {
    back("로그인 한 유저만 이용 가능한 서비스입니다");
    exit;
  }

  // [1단계 검사] 하나라도 시간대가 겹치면 즉시 중단 (exit)
  foreach ($seatArr as $seat) {
    if (db::fetch("select * from seats where ... 생략 ...")) {
      back("이미 사용자가 존재하는 좌석입니다");
      exit;
    }
  }

  // [2단계 저장] 1단계를 통과하면 전체 배열을 DB에 Insert
  foreach ($seatArr as $seat) {
    db::exec("insert into seats ... 생략 ...");
  }

  move("/reserve", "예약 성공");
});
```

- **동작 원리**: JS가 쉼표로 이어 붙인 문자열을 PHP `explode()`로 다시 배열로 분해한 뒤, 조회(select) → 검증 → 저장(insert) 순서의 파이프라인으로 DB에 최종 기록
