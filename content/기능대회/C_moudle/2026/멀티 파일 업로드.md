# 여러 파일 업로드 처리

## 1. HTML

`name`에 `[]`를 붙이고 `multiple` 추가

```html
<input type="file" name="file[]" multiple>
```

## 2. JS

FormData에 파일 개수만큼 반복해서 append

```javascript
const files = $("[name='file']").files

for (let i = 0; i < files.length; i++) {
  formData.append("file[]", files[i])
}
```

## 3. PHP

파일이 여러 개이면 `$_FILES["file"]`의 각 속성(`name`, `tmp_name` 등)이 **배열**로 전달됨

```php
$_FILES["file"] = [
  "name"     => ["a.png", "b.jpg"],
  "tmp_name" => ["/tmp/xxx", "/tmp/yyy"],
  ...
]
```

## 4. 반복문으로 하나씩 저장

```php
$images = [];
$file = $_FILES["file"];

foreach ($file["tmp_name"] as $i => $tmp) {
  if (!$tmp) continue;  // 파일이 없으면 건너뜀

  $path = "/asset/posts/" . $file["name"][$i];
  move_uploaded_file($tmp, "." . $path);
  $images[] = $path;
}

$image = implode(",", $images);  // "path1,path2,path3" 문자열로 합쳐 DB에 저장
```

## 핵심 포인트

| 항목 | 설명 |
| --- | --- |
| `name="file[]"` | `[]`가 있어야 PHP가 배열로 인식 |
| `$file["tmp_name"][$i]` | i번째 파일의 임시 경로 |
| `implode(",", $images)` | DB 컬럼 하나에 여러 경로를 콤마로 구분해 저장 (이후 `explode(",", $image)`로 다시 배열화) |
| `if (!$tmp) continue` | 빈 슬롯(파일을 선택하지 않은 input) 건너뜀 |
