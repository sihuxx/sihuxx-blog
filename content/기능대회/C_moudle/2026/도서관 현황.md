# 도서관 현황 지도 대시보드

**SVG 지도 시각화**와 **데이터 테이블 제어** 두 가지 기능을 수행하는 스크립트. 코드는 5개 영역으로 구분.

## 1. 유틸리티 함수 (DOM 제어 및 요소 생성)

자주 쓰는 DOM 탐색/생성 작업을 간소화하는 헬퍼 함수

```javascript
// CSS 선택자로 단일/다중 요소 탐색
const $ = (query) => document.querySelector(query);
const $$ = (query) => [...document.querySelectorAll(query)];

// JSON 데이터를 비동기로 불러오는 함수 (Promise 반환)
const $fetch = (path) => fetch(path).then((res) => res.json());

// 일반 HTML 요소 생성 (속성 포함)
// 예: createElement("div", { className: "box" }) -> <div class="box"></div> 반환
const createElement = (element, attrs = {}) => Object.assign(document.createElement(element), attrs);

// SVG 요소 생성 (SVG는 별도의 네임스페이스 지정 필수)
const createSvgElement = (element, attrs = {}) => {
  const el = document.createElementNS("http://www.w3.org/2000/svg", element);
  Object.entries(attrs).forEach(([k, v]) => el.setAttribute(k, v));
  return el;
};
```

- **핵심 역할**: 가독성을 높이고 반복 작업을 줄임. 특히 `createSvgElement`는 동적으로 차트를 그릴 때 필수.
- **동작 원리**: `document.createElement`로 빈 태그를 만든 뒤, `Object.assign`으로 넘긴 속성(`className`, `id` 등)을 한 번에 덧씌워 완성된 DOM 노드 생성

## 2. 데이터 초기화 및 통계 가공

JSON 데이터와 SVG 지도를 불러온 뒤, 지도에 표시할 **시도별 통계 데이터**를 산출

```javascript
const mapContainer = $("#map-container");

// 1) 데이터 및 지도 SVG 로드
const libs = await $fetch("./public/도서관현황.json");
await fetch("./public/southKoreaHigh.svg")
  .then((res) => res.text())
  .then((text) => {
    mapContainer.innerHTML = text; // 화면에 SVG 코드를 문자열로 주입
    return text;
  });

// 2) 전체 도서관 데이터를 순회하며 '시도명' 기준으로 그룹화 및 수치 합산
const libStats = libs.reduce((acc, lib) => {
  // acc["서울특별시"]가 없으면 기본 객체 생성 (널 병합 연산자)
  acc[lib["시도명"]] ??= { libCount: 0, bookCount: 0, seatCount: 0 };

  // 데이터 누적 합산
  acc[lib["시도명"]].libCount += 1;
  acc[lib["시도명"]].seatCount += +lib["열람좌석수"]; // +기호로 문자열을 숫자로 변환
  acc[lib["시도명"]].bookCount += +lib["자료수(도서)"];

  return acc; // 업데이트된 누적 객체 반환
}, {});
```

- **핵심 역할**: 수천 개의 도서관 데이터를 지역별(서울, 부산 등) 요약 통계(도서관 수, 책 수, 좌석 수)로 압축
- **동작 원리**
  - `reduce`가 빈 객체 `{}`(`acc`)에서 시작해 도서관 데이터를 하나씩 순회
  - 예를 들어 "서울특별시"가 처음 나오면 기본 객체(`{libCount: 0...}`)를 만들고 값을 누적
  - 순회가 끝나면 `libStats`에 `{"서울특별시": {libCount: 200...}, "경기도": {libCount: 350...}}` 형태의 객체가 완성

## 3. 지도 시각화 사전 준비

지도에 텍스트와 막대그래프를 알맞게 배치하기 위한 설정값 정의

```javascript
// SVG의 title 속성과 통계 데이터의 지역명을 맞추기 위한 매핑 객체
const nameMap = { 서울특별시: "서울", /* ...생략... */ };

// 지도 렌더링 시 UI가 겹치지 않도록 좌표를 미세 조정하는 오프셋
const posOffset = { 경상북도: { dx: -100, dy: 30 }, /* ...생략... */ };

// 막대 차트의 높이를 상대적으로 계산하기 위해 지표별 최소/최댓값 도출
const statsValues = Object.values(libStats); // 지역명 키를 빼고 통계 객체 배열만 추출
const statKeys = ["libCount", "bookCount", "seatCount"];
const minMax = {};

for (const key of statKeys) {
  // 예: [200, 350, 50, ...] 처럼 특정 지표의 숫자만 모은 배열 생성
  const values = statsValues.map((s) => s[key]);
  // 스프레드 문법으로 배열을 펼쳐 최대/최소값 계산 후 저장
  minMax[key] = { min: Math.min(...values), max: Math.max(...values) };
}

// 특정 값이 전체 데이터 중 어느 위치(0~100)에 해당하는지 계산
const percentile = (value, key) => {
  const { min, max } = minMax[key];
  return max === min ? 0 : ((value - min) / (max - min)) * 100;
};
```

- **핵심 역할**: 각 지역 데이터가 전체 중 어느 수준인지 파악해 그래프의 시각적 크기(높이)를 결정하는 기반 마련
- **동작 원리**
  - 지역마다 데이터 크기가 크게 다르므로, `map`으로 비교할 숫자만 뽑아 최댓값 `max`, 최솟값 `min` 저장
  - `percentile`은 `(내 값 - 최소) / (최대 - 최소) * 100` 정규화 공식으로 내 값을 0~100의 상대 수치로 변환
  - 이 %가 이후 막대그래프의 픽셀 높이가 됨

## 4. 지도 차트 및 툴팁 렌더링 (`renderMap`)

각 지역의 중앙 좌표를 구하고, 그 위에 미니 막대그래프와 툴팁 이벤트를 추가

```javascript
function renderMap() {
  const svg = $("svg");

  // 지도 내의 모든 지역(<path>) 순회
  $$("path[title]").forEach((path) => {
    const raw = path.getAttribute("title");
    const title = nameMap[raw] ?? raw;

    // getBBox()로 path의 가로세로 크기와 좌표를 구해 중앙점(cx, cy) 계산
    const bbox = path.getBBox();
    const cx = bbox.x + bbox.width / 2 + (posOffset[raw]?.dx || 0); // x시작점 + (너비의 절반) = 가로 중앙
    const cy = bbox.y + bbox.height / 2 + (posOffset[raw]?.dy || 0);

    const stats = libStats[raw];
    if (stats) {
      const g = createSvgElement("g", { cursor: "pointer" });

      // 3개의 지표별로 막대(<rect>)를 생성해 그룹(<g>)에 추가
      statKeys.forEach((key, i) => {
        const pct = percentile(stats[key], key); // 0~100 사이의 비율 계산
        const h = Math.max((pct / 100) * barMaxHeight, 1); // 백분율을 픽셀 높이(h)로 변환 (최소 1px)
        const bar = createSvgElement("rect", { /* x, y 좌표 및 h 높이 설정 */ });
        g.appendChild(bar);
      });

      // 마우스 오버 시 상세 정보를 보여주는 툴팁 이벤트
      g.addEventListener("mouseenter", (e) => { /* 툴팁 데이터 주입 및 노출 */ });
      g.addEventListener("mousemove", (e) => { /* 마우스 커서의 clientX, Y 좌표를 따라 툴팁 이동 */ });
      g.addEventListener("mouseleave", () => { /* 툴팁 display: none 처리 */ });

      // 지역명 텍스트(<text>) 추가
      const text = createSvgElement("text", { /* 텍스트 중앙 정렬 속성 설정 */ });
      text.textContent = title;

      g.appendChild(text);
      svg.appendChild(g); // 완성된 묶음(막대 3개 + 텍스트)을 SVG 지도 위에 삽입
    }
  });
}
```

- **핵심 역할**: 화면에 실제 시각 정보(그래프, 지역명, 툴팁)를 그리는 프론트엔드 핵심 로직
- **동작 원리**
  - `getBBox()`는 불규칙한 지도 조각을 감싸는 직사각형(Bounding Box)의 정보를 반환
  - 이 상자의 가로/세로 길이의 절반을 더하면 지역의 중앙 좌표(`cx`, `cy`)
  - 이 좌표를 기준으로 앞에서 구한 백분율을 픽셀(`h`)로 변환해 막대를 그리고, 마우스 위치(`e.clientX`, `e.clientY`)에 툴팁이 따라다니도록 이벤트 연결

## 5. 데이터 테이블 렌더링 및 필터링 (`renderTable`)

하단의 검색창과 정렬 옵션 변화를 감지해 테이블 목록을 실시간 갱신

```javascript
function renderTable() {
  const keyword = searchInput.value.trim();
  const sortOrder = sortSelect.value;

  // 1) 데이터 정렬 (원본을 건드리지 않도록 복사본 [...] 사용 후 정렬)
  const sorted = [...libs].toSorted((a, b) => {
    if (sortOrder) {
      const diff = (+a["자료수(도서)"] || 0) - (+b["자료수(도서)"] || 0);
      return sortOrder === "asc" ? diff : -diff; // 양수/음수 반환으로 오름차순/내림차순 결정
    }
    return (a["시도명"] || "").localeCompare(b["시도명"] || ""); // 가나다순 정렬
  });

  // 2) 데이터 검색 (도서관명에 키워드가 포함된 항목만 남긴 새 배열 생성)
  const filtered = keyword ? sorted.filter((lib) => lib["도서관명"]?.includes(keyword)) : sorted;

  // 3) HTML 테이블 행(<tr>, <td>) 문자열 조립 및 DOM 삽입
  tbody.innerHTML = filtered.map((lib) => {
    // 안쪽 map: 각 컬럼 데이터를 <td>문자열</td>로 변환 후 join으로 합침
    const cells = columns.map((col) => {
      const val = lib[col] ?? "";
      // 검색 키워드를 <mark> 태그로 감싸 하이라이트
      if (col === "도서관명" && keyword) {
        return `<td>${val.replaceAll(keyword, `<mark>${keyword}</mark>`)}</td>`;
      }
      return `<td>${val}</td>`;
    }).join("");

    // 바깥쪽 map 반환: 합친 td들을 <tr>로 감쌈
    return `<tr>${cells}</tr>`;
  }).join(""); // 수백 개의 <tr> 문자열을 하나의 텍스트로 합침
}

// 사용자 입력 이벤트가 발생할 때마다 테이블을 다시 그림
sortSelect.addEventListener("change", renderTable);
searchInput.addEventListener("input", renderTable);
renderTable(); // 최초 로드 시 1회 실행
```

- **핵심 역할**: 검색, 정렬 같은 사용자 상호작용으로 원하는 데이터를 찾을 수 있도록 테이블 UI를 동적으로 제어
- **동작 원리**
  - 글자를 입력하거나 셀렉트 박스를 바꿀 때마다 함수가 실행되고, `toSorted`와 `filter`로 조건에 맞는 데이터만 추출
  - 렌더링은 **메서드 체이닝** 사용: 객체 하나를 `<td>` 여러 개로 만들어 합치고(`.join("")`), `<tr>`로 감쌈
  - 만들어진 `<tr>...</tr>` 문자열 배열을 다시 `.join("")`으로 하나의 HTML 문자열로 만들어 `innerHTML`에 한 번에 주입
