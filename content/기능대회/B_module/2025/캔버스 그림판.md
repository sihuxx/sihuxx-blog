# 캔버스 그림판

#기능대회

## 1. 도화지(Canvas)와 붓(Context) 준비

HTML에 캔버스 태그를 만들고 자바스크립트로 그릴 준비를 함

- 목표: 흰색 사각형 화면 띄우기

### HTML

```html
<canvas id="jsCanvas" width="700" height="500"></canvas>
```

### JavaScript

```javascript
const canvas = document.getElementById("jsCanvas");
const ctx = canvas.getContext("2d"); // 2D 그리기 도구(붓) 가져오기

// 캔버스 배경을 흰색으로 칠함 (생략하면 저장 시 배경이 투명해짐)
ctx.fillStyle = "white";
ctx.fillRect(0, 0, canvas.width, canvas.height);

// 붓 기본 설정
ctx.strokeStyle = "black"; // 검은색 붓
ctx.lineWidth = 2.5;       // 붓 두께
```

## 2. 마우스 움직임 감지와 선 긋기

그림판의 핵심 논리로, 마우스 상태에 따라 동작을 분기함

- **클릭 안 하고** 움직이면: 붓 위치만 이동 (`moveTo`)
- **클릭하고** 움직이면: 선을 그림 (`lineTo` + `stroke`)
- 목표: 마우스로 검은 선 그리기

### JavaScript (추가)

```javascript
let painting = false; // 현재 클릭 중인지 기억하는 변수(스위치)

function stopPainting() {
  painting = false; // 클릭을 뗌
}

function startPainting() {
  painting = true;  // 클릭함
  ctx.beginPath();  // 중요: 이전 선과 이어지지 않도록 새 경로 시작
}

function onMouseMove(event) {
  // 마우스의 현재 좌표
  const x = event.offsetX;
  const y = event.offsetY;

  if (!painting) {
    // 그리는 중이 아님: 붓을 좌표로 옮기기만 함 (시작점 설정)
    ctx.moveTo(x, y);
  } else {
    // 그리는 중: 붓을 움직여 선을 그림
    ctx.lineTo(x, y);
    ctx.stroke();
  }
}

// 이벤트 연결
if (canvas) {
  canvas.addEventListener("mousemove", onMouseMove);   // 마우스 움직일 때
  canvas.addEventListener("mousedown", startPainting); // 누를 때
  canvas.addEventListener("mouseup", stopPainting);    // 뗄 때
  canvas.addEventListener("mouseleave", stopPainting); // 캔버스 밖으로 나갔을 때
}
```

## 3. 색상과 굵기 바꾸기

HTML에 컨트롤 패널(Input)을 추가하고 JS와 연결

- 목표: 파란색 굵은 선 그리기

### HTML (추가)

```html
<input type="color" id="jsColor" value="#000000">
<input type="range" id="jsRange" min="0.1" max="20" value="2.5" step="0.1">
```

### JavaScript (추가)

```javascript
const colors = document.getElementById("jsColor");
const range = document.getElementById("jsRange");

// 1. 색상 변경 감지 ('change' 이벤트)
colors.addEventListener("change", (e) => {
  const color = e.target.value;
  ctx.strokeStyle = color; // 선 색 변경
  ctx.fillStyle = color;   // 채우기 색도 변경
});

// 2. 굵기 변경 감지 ('input' 이벤트, 슬라이더를 움직일 때마다)
range.addEventListener("input", (e) => {
  const size = e.target.value;
  ctx.lineWidth = size;
});
```

## 4. 지우개와 전체 지우기

지우개는 별도 도구가 아닌 **흰색 붓**

- 목표: 그림 지우기 및 초기화 기능 구현

### HTML (추가)

```html
<button id="eraserBtn">지우개</button>
<button id="clearBtn">전체 삭제</button>
```

### JavaScript (추가)

```javascript
const eraserBtn = document.getElementById("eraserBtn");
const clearBtn = document.getElementById("clearBtn");

// 1. 지우개 버튼 클릭: 붓 색을 흰색으로 변경
eraserBtn.addEventListener("click", () => {
  ctx.strokeStyle = "white";
});

// 2. 전체 삭제: 캔버스 크기만큼 흰색 사각형으로 덮어쓰기
clearBtn.addEventListener("click", () => {
  ctx.fillStyle = "white";
  ctx.fillRect(0, 0, canvas.width, canvas.height);
});
```

## 5. 저장하기

그린 그림을 이미지 파일로 변환해 다운로드

- 목표: 그림을 PNG 파일로 저장

### HTML (추가)

```html
<button id="saveBtn">저장하기</button>
```

### JavaScript (추가)

```javascript
const saveBtn = document.getElementById("saveBtn");

saveBtn.addEventListener("click", () => {
  // 1. 캔버스의 그림을 URL 문자열로 변환
  const image = canvas.toDataURL("image/png");

  // 2. 가상의 <a> 태그(링크) 생성
  const link = document.createElement("a");
  link.href = image;          // 링크 주소는 그림 데이터
  link.download = "art.png";  // 다운로드될 파일 이름

  // 3. 링크를 클릭해 다운로드 실행
  link.click();
});
```
