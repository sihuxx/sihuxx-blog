# 헤더 서브메뉴 (focus-trap 방식)

## 주요 코드

```html
<li class="has-sub">
  <input class="focus-trap">
  <label class="menu-label">도서관소개</label>
  <ul class="sub">...</ul>
</li>
```

```css
/* 숨겨진 Input 버튼 역할 */
.focus-trap { position: absolute; inset: 0; opacity: 0; cursor: pointer; z-index: 2; }

/* 클릭 시 서브메뉴 노출 및 아이콘 변경 */
.focus-trap:focus ~ .sub { max-height: 500px; opacity: 1; }
.focus-trap:focus ~ .menu-label::after { content: '-'; transform: rotate(180deg); }

/* 마우스 이탈 시 강제 포커스 해제 트릭 */
.has-sub:not(:hover) .focus-trap { animation: kill-focus .001s forwards; }
@keyframes kill-focus {from { display: none; } to { display: block; }}
```

## 기능 설명

- **클릭 및 토글 로직**
  - 메뉴 텍스트 위에 투명한 `<input>`(`.focus-trap`)을 덮어씌움
  - 메뉴를 클릭하면 input에 포커스(`:focus`)가 잡힘
  - 형제 선택자(`~`)로 닫혀 있던 `.sub`의 `max-height`와 `opacity`를 변경해 서브메뉴가 부드럽게 펼쳐짐
- **아이콘 회전**
  - 포커스 상태에서 라벨 가상 요소(`::after`)의 텍스트를 `+`에서 `-`로 변경하고 180도 회전(`transform: rotate`)
- **마우스 아웃 초기화**
  - CSS만으로는 포커스 해제(blur)가 어려움
  - 마우스가 영역을 벗어나면(`:not(:hover)`) 아주 짧은 애니메이션으로 요소를 잠깐 숨겼다 나타나게 해서 포커스를 강제로 해제하는 트릭 사용
