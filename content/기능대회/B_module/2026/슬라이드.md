# 슬라이더 (12초 주기 동기화)

#기능대회

## 1. HTML 구조 (Layering)

슬라이더는 **3개의 층(Layer)** 으로 구성되어 시각적 깊이감을 줌

- **Bottom (슬라이더)**: `400%` 너비의 실제 이미지가 지나가는 바닥층
- **Middle (배경)**: `z-index: 5`인 장식용 배경 이미지(`.background`), 슬라이드 위에 있지만 텍스트보다는 아래
- **Top (콘텐츠)**: `z-index: 50`인 텍스트와 `z-index: 15`인 프로그레스 바가 최상단에서 정보 전달

## 2. 핵심 로직: 12초 주기 동기화

모든 요소가 **12초** 주기를 공유해 동기화됨

| 요소 | 주기 | 세부 로직 |
| :--- | :--- | :--- |
| **메인 슬라이드** | `12s` | 전체 너비의 25%씩 이동하며 4개 화면 순환 (X축 이동) |
| **텍스트 박스** | `12s` | `animation-delay`를 3초 간격(`0s, 3s, 6s, 9s`)으로 지정해 슬라이드 시점과 일치 |
| **프로그레스 바** | `3s` | 슬라이드가 한 장 머무는 3초마다 0%에서 100%로 채워짐 |

## 3. 핵심 CSS

### 슬라이드 이동 (Step 이동)

계속 흐르지 않고 `0%~20%` 구간에서 멈춰 있다가 `20%~25%` 구간에서 빠르게 이동

```css
@keyframes slide {
  0%, 20% { transform: translateX(0); }       /* 1번 슬라이드 정지 */
  25%, 45% { transform: translateX(-25%); }   /* 2번 슬라이드 정지 */
  50%, 70% { transform: translateX(-50%); }   /* 3번 슬라이드 정지 */
  75%, 95% { transform: translateX(-75%); }   /* 4번 슬라이드 정지 */
  100% { transform: translateX(0); }          /* 다시 처음으로 */
}
```

### 텍스트 페이드인/아웃

텍스트는 슬라이드보다 짧은 구간 안에서 나타났다 사라져야 가독성이 좋음

```css
@keyframes textSlide {
  0%, 5% { opacity: 0; transform: translateY(30px); }     /* 등장 전 숨김 */
  10%, 20% { opacity: 1; transform: translateY(0); }      /* 등장 및 유지 */
  25%, 100% { opacity: 0; transform: translateY(-20px); } /* 퇴장 */
}
```

### 프로그레스 바 (Linear Gradient)

`:root` 변수를 활용한 그라데이션과 무한 반복

```css
.progress-bar span {
  width: 0; height: 100%;
  background: linear-gradient(90deg, var(--grn), var(--yel)); /* 색상 동기화 */
  animation: barRun 3s infinite linear; /* 슬라이드 1장당 3초 주기로 초기화 */
}
```
