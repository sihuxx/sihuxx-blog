# 2026 contest C practice 디자인 수정 목록

## 공통

- 메인 컬러 변경 (너무 쨍함)
- 콘텐츠 영역 타이틀과 콘텐츠를 들여쓰기로 분리
- 닫기 버튼 디자인 통일
- 로고 새로 제작
- 폼 / 테이블 디자인 통일
- 전체 이미지를 텍스트에 어울리는 이미지로 교체

## main 페이지

### 비주얼

- 타이틀 텍스트 자간 넓히기
- 비주얼 이미지를 더 오른쪽으로 이동
- 타이틀 텍스트의 흰색 border 영역 줄이기

### 도서관 소식

- 공지사항 사이 패딩 줄이기
- border 컬러 변경
- 날짜 강조 줄이기

### 자주 찾는 메뉴

![alt text](../image.png)

- 위 형식으로 디자인 변경
- hover 시 살짝 위로 올라오게 처리
- 이미지 위에 폰트어썸, 메뉴 이름 순으로 세로 정렬

### 프로그램

- 이미지 크기 줄이기
- 상단 번호 삭제
- 올라오는 프로그램 제목 디자인 변경 (검정 섀도우 또는 깔끔한 흰색)
- 프로그램 모달 닫기 버튼 디자인 변경

### 행사 달력

- 달력 구분선 제작
- 저번 달, 다음 달은 연한 회색으로 남겨 월 영역이 보이게 처리
- box-shadow 줄이기
- select 디자인 변경 (오른쪽으로 조금 넓게)

### 추천 도서

- 추천도서 영역을 넓히고 lorem 텍스트 추가
- 추천도서 영역 border-radius 줄이기
- 추천 도서 마크 수정
- 버튼 디자인 변경

### 푸터

- 디자인 전면 재작성
- 대중적인 디자인을 참고하되 눈에 띄지 않게 수정

## sub 페이지

- 설립 목적 및 사업 소개 영역 디자인 수정
