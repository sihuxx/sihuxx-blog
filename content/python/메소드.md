## 1. 문자열 (str) — 가장 많음

> 중요: 문자열은 **수정 불가(immutable)**. 모든 메소드가 원본을 안 바꾸고 **새 문자열을 돌려줍니다.**
> 리스트가 "연필로 쓴 노트"라면 문자열은 "인쇄된 종이" — 고치려면 새로 뽑아야 해요.

### 대소문자
| 이름 | 기능 | 예제 |
|---|---|---|
| `upper()` | 전부 대문자 | `"ab".upper()` → `'AB'` |
| `lower()` | 전부 소문자 | `"AB".lower()` → `'ab'` |
| `capitalize()` | 첫 글자만 대문자 | `"hi you".capitalize()` → `'Hi you'` |
| `title()` | 각 단어 첫 글자 대문자 | `"hi you".title()` → `'Hi You'` |
| `swapcase()` | 대↔소 뒤집기 | `"aB".swapcase()` → `'Ab'` |

### 공백·문자 제거
| 이름 | 기능 | 예제 |
|---|---|---|
| `strip()` | 양쪽 공백 제거 | `"  hi ".strip()` → `'hi'` |
| `lstrip()` `rstrip()` | 왼쪽/오른쪽만 | `"xxhi".lstrip('x')` → `'hi'` |
| `removeprefix()` | 앞부분 제거 (3.9+) | `"unhappy".removeprefix("un")` → `'happy'` |
| `removesuffix()` | 뒷부분 제거 (3.9+) | `"a.txt".removesuffix(".txt")` → `'a'` |

### 찾기·세기
| 이름 | 기능 | 예제 |
|---|---|---|
| `find(x)` | 위치 찾기, **없으면 -1** | `"abc".find("b")` → `1` |
| `rfind(x)` | 뒤에서부터 찾기 | `"aba".rfind("a")` → `2` |
| `index(x)` | 위치 찾기, **없으면 에러** | `"abc".index("b")` → `1` |
| `rindex(x)` | 뒤에서부터 (없으면 에러) | `"aba".rindex("a")` → `2` |
| `count(x)` | 개수 | `"aab".count("a")` → `2` |
| `startswith(x)` | ~로 시작하나 | `"abc".startswith("a")` → `True` |
| `endswith(x)` | ~로 끝나나 | `"a.png".endswith(".png")` → `True` |

### 바꾸기·나누기·합치기
| 이름 | 기능 | 예제 |
|---|---|---|
| `replace(a,b)` | 바꾸기 | `"aaa".replace("a","b",2)` → `'bba'` |
| `split(구분자)` | 나눠서 리스트로 | `"a,b".split(",")` → `['a','b']` |
| `rsplit()` | 뒤에서부터 나누기 | `"a.b.c".rsplit(".",1)` → `['a.b','c']` |
| `splitlines()` | 줄 단위로 나누기 | `"a\nb".splitlines()` → `['a','b']` |
| `partition(x)` | (앞, 구분자, 뒤) 3조각 | `"a=1".partition("=")` → `('a','=','1')` |
| `join(리스트)` | 리스트를 문자열로 | `"-".join(['a','b'])` → `'a-b'` |

### 정렬·채우기
| 이름 | 기능 | 예제 |
|---|---|---|
| `zfill(n)` | 0으로 앞 채우기 | `"7".zfill(3)` → `'007'` |
| `ljust(n)` `rjust(n)` | 좌/우 정렬 | `"a".rjust(3,'*')` → `'**a'` |
| `center(n)` | 가운데 정렬 | `"a".center(5,'-')` → `'--a--'` |
| `format()` | 서식 채우기 | `"{}세".format(20)` → `'20세'` |
| `expandtabs()` | 탭을 공백으로 | `"a\tb".expandtabs(4)` |

### 판별 (전부 True/False 반환)
| 이름 | 기능 | 예제 |
|---|---|---|
| `isdigit()` | 숫자로만 | `"12".isdigit()` → `True` |
| `isalpha()` | 글자로만 | `"ab".isalpha()` → `True` |
| `isalnum()` | 글자+숫자만 | `"a1".isalnum()` → `True` |
| `isspace()` | 공백만 | `"  ".isspace()` → `True` |
| `isupper()` `islower()` | 전부 대/소문자 | `"AB".isupper()` → `True` |
| `istitle()` | 제목 형식인가 | `"Hi You".istitle()` → `True` |
| `isnumeric()` `isdecimal()` | 숫자 판별 (범위 다름) | `"½".isnumeric()` → `True` |

## 3. 튜플 (tuple) — 딱 2개

> 튜플은 **수정 불가**라서 "읽기 전용" 메소드만 있어요.

| 이름 | 기능 | 예제 |
|---|---|---|
| `count(x)` | 개수 | `(1,2,2).count(2)` → `2` |
| `index(x)` | 위치 | `(1,2,3).index(3)` → `2` |

```python
# 튜플은 값 교환에 자주 씀
a, b = b, a
# 괄호 없어도 튜플
t = 1, 2, 3
# 원소 1개짜리는 쉼표 필수!
t = (1,)        # 튜플
t = (1)         # 그냥 정수 1
```

## 4. 딕셔너리 (dict) — 실무에서 리스트만큼 중요

> 딕셔너리는 **이름표 붙은 사물함**. 번호(인덱스) 대신 이름(키)으로 꺼내요.

| 이름 | 기능 | 예제 |
|---|---|---|
| `keys()` | 키 목록 | `d.keys()` → `dict_keys(['a'])` |
| `values()` | 값 목록 | `d.values()` |
| `items()` | (키,값) 쌍 목록 | `for k,v in d.items():` |
| `get(키, 기본값)` | 안전하게 꺼내기 | `d.get('x', 0)` → 없으면 `0` |
| `setdefault(키, 값)` | 없으면 만들고 반환 | `d.setdefault('a', [])` |
| `update(다른딕)` | 병합/갱신 | `d.update({'b':2})` |
| `pop(키)` | 꺼내면서 삭제 | `d.pop('a')` |
| `popitem()` | 마지막 쌍 꺼내기 | `d.popitem()` |
| `clear()` | 전부 비우기 | `d.clear()` |
| `copy()` | 복사본 | `e = d.copy()` |
| `fromkeys(키들, 값)` | 키 목록으로 새 딕셔너리 | `dict.fromkeys('ab', 0)` → `{'a':0,'b':0}` |

```python
d = {'사과': 1000, '배': 2000}

d['포도'] = 3000          # 추가/수정
del d['배']               # 삭제
'사과' in d               # True  ← 키 기준으로 검사

# get vs [] 의 차이 (초보자 필수)
d['없는키']               # ❌ KeyError
d.get('없는키')           # ✅ None
d.get('없는키', 0)        # ✅ 0

# 딕셔너리 컴프리헨션
{k: v*2 for k, v in d.items()}

# 값 기준 정렬
sorted(d.items(), key=lambda x: x[1], reverse=True)
```

## 5. 집합 (set) — 중복 없는 주머니

> 순서가 없고 중복도 없어요. **"중복 제거"와 "교집합/차집합"** 할 때 씁니다.

| 이름 | 기능 | 예제 |
|---|---|---|
| `add(x)` | 1개 추가 | `s.add(4)` |
| `update(집합)` | 여러 개 추가 | `s.update([4,5])` |
| `remove(x)` | 삭제 (없으면 에러) | `s.remove(1)` |
| `discard(x)` | 삭제 (없어도 조용) | `s.discard(99)` |
| `pop()` | 아무거나 꺼내기 | `s.pop()` |
| `clear()` | 비우기 | `s.clear()` |
| `copy()` | 복사 | `t = s.copy()` |
| `union(b)` | 합집합 `\|` | `{1,2}.union({3})` → `{1,2,3}` |
| `intersection(b)` | 교집합 `&` | `{1,2} & {2,3}` → `{2}` |
| `difference(b)` | 차집합 `-` | `{1,2} - {2}` → `{1}` |
| `symmetric_difference(b)` | 대칭차 `^` | `{1,2} ^ {2,3}` → `{1,3}` |
| `issubset(b)` | 부분집합인가 | `{1}.issubset({1,2})` → `True` |
| `issuperset(b)` | 상위집합인가 | `{1,2}.issuperset({1})` → `True` |
| `isdisjoint(b)` | 겹치는 게 없나 | `{1}.isdisjoint({2})` → `True` |

```python
# 가장 많이 쓰는 용도
list(set([1,1,2,3]))            # 중복 제거 → [1,2,3]

# 두 리스트의 공통 원소
set(a) & set(b)

# 빈 집합은 {}가 아니라 set()
s = set()       # ✅
s = {}          # ❌ 이건 빈 딕셔너리
```

## 6. 파일 객체

| 이름 | 기능 | 예제 |
|---|---|---|
| `read()` | 전체를 문자열로 | `f.read()` |
| `readline()` | 한 줄 읽기 | `f.readline()` |
| `readlines()` | 전체를 리스트로 | `f.readlines()` |
| `write(s)` | 쓰기 | `f.write("안녕")` |
| `writelines(리스트)` | 여러 줄 쓰기 | `f.writelines(['a\n','b'])` |
| `close()` | 닫기 | `f.close()` |
| `seek(n)` | 읽는 위치 이동 | `f.seek(0)` (처음으로) |
| `tell()` | 현재 위치 | `f.tell()` |

```python
# with를 쓰면 close() 자동 (권장)
with open('a.txt', 'w', encoding='utf-8') as f:
    f.write("안녕")

with open('a.txt', encoding='utf-8') as f:
    for line in f:          # 한 줄씩, 메모리 효율적
        print(line.strip())
```

**모드**: `'r'` 읽기 / `'w'` 새로쓰기(기존 삭제) / `'a'` 이어쓰기 / `'b'` 바이너리
