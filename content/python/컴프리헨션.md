## 1. 개념
직관적으로 파이썬의 자료구조 (list, dictionary, set)에 for문과 if문을 한 줄로 줄여서 데이터를 좀 더 쉽고 간결하게 담기 위한 문법이다. 

## 2. 컴프리헨션
### 2-1. 기본

```python
# 기본
arr = []
for i in range(5):
    arr.append(i)

# 컴프리헨션
arr = [i for i in range(5)]
```
```
[결과 for 변수 in 반복]
```

### 2-2. 조건
```python
# 기본
arr = []
for i in range(10):
    if i % 2 == 0:
        arr.append(i)

# 컴프리헨션
짝수 = [i for i in range(10) if i % 2 == 0]
# [0, 2, 4, 6, 8]
```
```
[결과 for 변수 in 반복 if 조건]
```
if만 사용하는 경우 → 뒤에 작성 (조건에 맞는 값만 골라내는 역할)

### 2-3. if else
```python
# 기본
arr = []
for i in range(5):
    if i % 2 == 0:
        arr.append(i)
    else:
        arr.append(-1)

# 컴프리헨션
arr = [i if i % 2 == 0 else -1 for i in range(5)]
# [0, -1, 2, -1, 4]
```
if else를 사용하는 경우 → 앞에 작성 (조건에 따라 어떤 값을 넣을지 선택하는 역할)

### 2-4. 2중 반복
```python
# 기본
arr = []
for i in range(2):
    for j in range(3):
        arr.append((i, j))

# 컴프리헨션
for i in range(2):
    for j in range(3):
        ...
arr = [(i, j) for i in range(2) for j in range(3)]
```


## 3. 종류
| 종류 | 결과 |
| --- | --- |
| 리스트 컴프리헨션 | `[]` 리스트 생성 |
| 딕셔너리 컴프리헨션 | `{key: value}` 딕셔너리 생성 |
| 셋 컴프리헨션 | `{}` 집합(Set) 생성 |

### 3-1. 리스트 컴프리헨션
```python
arr = [i for i in range(5)]
# [0, 1, 2, 3, 4]
```

### 3-2. 딕셔너리 컴프리헨션
```python
dic = {i: i * 10 for i in range(5)}
# {0:0, 1:10, 2:20, 3:30, 4:40}
```
```
{key: value for 변수 in 반복}
```

### 3-3. 셋 컴프리헨션
```python
s = {i % 3 for i in range(6)}
# {0, 1, 2}
```

## 4. 심화
# 4. 컴프리헨션 심화
### 4-1. 중첩 컴프리헨션
```python
# 기본
arr = []

for row in [[1, 2], [3, 4], [5, 6]]:
    for x in row:
        arr.append(x)

# 컴프리헨션
arr = [x for row in [[1, 2], [3, 4], [5, 6]] for x in row]

# [1, 2, 3, 4, 5, 6]
```

### 4-2. 중첩 반복 + 조건
```python
# 기본
arr = []

for i in range(3):
    for j in range(3):
        if i != j:
            arr.append((i, j))

# 컴프리헨션
arr = [(i, j) for i in range(3) for j in range(3) if i != j]
```

### 4-3. 딕셔너리 심화
```python
# 기본
dic = {}

for i in range(5):
    dic[i] = i * i

# 컴프리헨션
dic = {i: i * i for i in range(5)}
```
```python
dic = {i: i * i for i in range(10) if i % 2 == 0}
```

### 4-4. 셋 + 조건
```python
# 기본
s = set()

for i in range(10):
    if i % 2 == 0:
        s.add(i)

# 컴프리헨션
s = {i for i in range(10) if i % 2 == 0}

# {0, 2, 4, 6, 8}
```

### 4-5. 컴프리헨션 안에서 함수 사용
```python
def square(x):
    return x * x

arr = [square(i) for i in range(5)]

# [0, 1, 4, 9, 16]
```
