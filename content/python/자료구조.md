## 0. 자료구조란

- 데이터를 **어떤 형태의 그릇에 담을 것인가**를 정하는 것이다.
- 같은 물이라도 물병 / 냄비 / 얼음틀에 담는 목적이 다르듯, 데이터도 목적에 따라 담는 그릇이 달라진다.
- 파이썬의 기본 자료구조는 **리스트 · 튜플 · 딕셔너리 · 집합** 4가지이다.

---

## 1. 리스트 (list)

> 비유: **번호표가 달린 신발장**. 번호로 찾고, 자유롭게 넣고 뺄 수 있다.

```python
a = [10, 20, 30]
```

### 특징

- **순서가 있다** → 인덱스(번호)로 접근한다.
- **수정이 가능하다(mutable)** → 값 변경 · 추가 · 삭제가 자유롭다.
- **중복을 허용한다** → `[1, 1, 1]`이 가능하다.

### 기본 사용

```python
a[0] = 99          # 값 교체
a.append(40)       # 뒤에 추가
a.insert(0, 5)     # 중간 삽입
a.remove(20)       # 값으로 삭제
x = a.pop()        # 꺼내면서 삭제
```

### 주요 메소드

| 메소드 | 기능 |
|---|---|
| `append(x)` | 뒤에 1개 추가 |
| `extend(리스트)` | 풀어서 이어붙이기 |
| `insert(i, x)` | i번 위치에 삽입 |
| `remove(x)` | 값 기준 첫 번째 삭제 |
| `pop(i)` | 위치 기준 꺼내며 삭제 |
| `index(x)` | 위치 반환 |
| `count(x)` | 개수 반환 |
| `sort()` | 원본 정렬 |
| `reverse()` | 순서 뒤집기 |
| `copy()` | 얕은 복사 |
| `clear()` | 전체 삭제 |

### 사용처

- 순서가 의미를 갖는 데이터에 쓴다.
- 예: 성적 목록, 할 일 목록, 게임 아이템 순서, 경로 좌표 목록.

### 주의점

- `a.sort()`는 원본을 바꾸고 `None`을 반환한다. 새 리스트가 필요하면 `sorted(a)`를 쓴다.
- `b = a`는 복사가 아니라 별명이다. 복사는 `a.copy()` 또는 `a[:]`를 쓴다.
- 반복문을 돌면서 `remove()`로 삭제하면 요소를 건너뛴다. 컴프리헨션으로 새로 만드는 편이 안전하다.

## 2. 튜플 (tuple)

> 비유: **본드로 굳혀놓은 신발장**. 리스트와 생김새는 같으나 내용물을 바꿀 수 없다.

```python
t = (10, 20, 30)
t[0] = 99          # TypeError — 수정 불가
```

### 특징

- **순서가 있다.**
- **수정이 불가능하다(immutable).**
- **중복을 허용한다.**

### 수정 불가 구조를 쓰는 이유

1. **값이 바뀌면 안 되는 데이터를 보호한다.** — 좌표 `(37.5, 127.0)`, RGB `(255, 0, 0)` 등.
2. **리스트보다 빠르고 메모리를 덜 쓴다.** — 변경을 고려하지 않아 내부적으로 최적화된다.
3. **딕셔너리의 키로 사용할 수 있다.** — 리스트는 키가 될 수 없다.

### 주요 메소드

- `count(x)` — 개수 반환
- `index(x)` — 위치 반환
- 수정이 불가하므로 **읽기 전용 메소드 2개뿐이다.**

### 자주 만나는 형태

```python
x, y = (1, 2)                       # 언패킹
a, b = b, a                         # 값 교환
for i, v in enumerate(['a', 'b']):  # 내부적으로 튜플이 반환된다
```

### 주의점

- 원소가 1개일 때는 쉼표가 필수이다.
  - `(1,)` → 튜플
  - `(1)` → 정수 1

## 3. 딕셔너리 (dict)

> 비유: **번호 대신 이름표가 붙은 신발장**. "3번 칸"이 아니라 "시후 칸"으로 찾는다.

```python
d = {'사과': 1000, '배': 2000}
d['사과']           # 1000
d['포도'] = 3000    # 추가
del d['배']         # 삭제
```

### 특징

- **키(key) → 값(value)** 의 쌍으로 저장한다.
- 키는 중복될 수 없고, 수정 불가 자료형(문자열·숫자·튜플)만 키가 된다.
- Python 3.7부터 입력 순서가 유지된다.

### 리스트와의 결정적 차이 — 탐색 속도

| 구분 | 리스트 | 딕셔너리 |
|---|---|---|
| 탐색 방식 | 앞에서부터 하나씩 확인 | 키를 계산해 위치로 직행 |
| 시간복잡도 | O(n) | **O(1)** |

- 딕셔너리는 **해시(hash)** 를 사용해 키로부터 저장 위치를 즉시 계산한다.
- 데이터가 100만 개여도 탐색 시간이 거의 일정하다. 이것이 딕셔너리를 쓰는 가장 큰 이유이다.

### 주요 메소드

| 메소드 | 기능 |
|---|---|
| `keys()` | 키 목록 |
| `values()` | 값 목록 |
| `items()` | (키, 값) 쌍 목록 |
| `get(키, 기본값)` | 안전하게 값 조회 |
| `setdefault(키, 값)` | 없으면 생성 후 반환 |
| `update(딕셔너리)` | 병합·갱신 |
| `pop(키)` | 꺼내며 삭제 |
| `clear()` | 전체 삭제 |

### 사용처

- "A는 B이다" 형태의 대응 관계에 쓴다.
- 예: 이름 → 점수, 상품 → 가격, 아이디 → 회원정보, 설정값 저장.

### 주의점

- 없는 키를 `d['키']`로 접근하면 `KeyError`가 발생한다. `d.get('키', 기본값)`이 안전하다.
- `in` 연산자는 **키를 기준으로** 검사한다.

## 4. 집합 (set)

> 비유: **같은 구슬을 넣으면 튕겨내는 주머니**. 주머니이므로 순서도 없다.

```python
s = {1, 2, 3}
{1, 1, 2}          # {1, 2} — 중복 자동 제거
s[0]               # TypeError — 인덱스 접근 불가
```

### 특징

- **중복을 허용하지 않는다.**
- **순서가 없다** → 인덱스로 접근할 수 없다.
- 딕셔너리와 같은 해시 구조를 쓰므로 **포함 여부 검사가 매우 빠르다.**

### 주요 용도

```python
# 1) 중복 제거
list(set([1, 1, 2, 3]))     # [1, 2, 3]

# 2) 집합 연산
a = {1, 2, 3}
b = {3, 4}
a & b      # {3}         교집합
a | b      # {1,2,3,4}   합집합
a - b      # {1, 2}      차집합
a ^ b      # {1,2,4}     대칭차집합

# 3) 빠른 포함 검사
if x in 집합:    # O(1)
if x in 리스트:  # O(n)
```

### 주요 메소드

| 메소드 | 기능 |
|---|---|
| `add(x)` | 1개 추가 |
| `update(집합)` | 여러 개 추가 |
| `remove(x)` | 삭제 (없으면 에러) |
| `discard(x)` | 삭제 (없어도 무시) |
| `union()` / `intersection()` / `difference()` | 합·교·차집합 |
| `issubset()` / `issuperset()` | 부분·상위집합 판별 |

### 주의점

- 빈 집합은 `set()`으로 만든다. `{}`는 **빈 딕셔너리**이다.
- 순서가 보장되지 않으므로 순서가 중요하면 집합을 쓰면 안 된다.

---

## 5. 비교 정리

| 구분 | 리스트 | 튜플 | 딕셔너리 | 집합 |
|---|---|---|---|---|
| 기호 | `[ ]` | `( )` | `{키: 값}` | `{ }` |
| 순서 | O | O | O (3.7+) | **X** |
| 수정 | O | **X** | O | O |
| 중복 | O | O | 키는 X | **X** |
| 접근 | `a[0]` | `t[0]` | `d['키']` | 불가 |
| 탐색 속도 | O(n) | O(n) | **O(1)** | **O(1)** |

---

## 6. 선택 기준

다음 순서로 판단하면 대부분 맞는다.

1. **이름(키)으로 찾아야 하는가?** → 딕셔너리
2. **중복 제거 또는 포함 여부 확인이 목적인가?** → 집합
3. **절대 변하지 않는 고정값인가?** → 튜플
4. **그 외 전부** → 리스트

## 7. 중첩 구조

자료구조는 서로 겹쳐 쌓을 수 있으며, 실무에서는 대부분 중첩 형태로 쓰인다.

### 리스트 안의 딕셔너리

가장 흔한 형태이며, JSON 데이터의 구조와 같다.

```python
학생들 = [
    {'이름': '시후', '점수': 95},
    {'이름': '민수', '점수': 88},
]

for s in 학생들:
    print(s['이름'], s['점수'])

학생들.sort(key=lambda x: x['점수'], reverse=True)
```

### 딕셔너리 안의 리스트

그룹으로 묶을 때 쓴다.

```python
반별 = {
    '1반': ['시후', '민수'],
    '2반': ['영희'],
}
반별['1반'].append('철수')
```

### 튜플의 리스트

좌표처럼 고정된 쌍이 여러 개일 때 쓴다.

```python
경로 = [(37.5, 127.0), (37.6, 127.1)]
```

## 8. 응용 자료구조

기본 4종을 응용한 구조이며, 이름과 개념만 알아두어도 도움이 된다.

### 스택 (Stack) — LIFO

> 비유: **프링글스 통**. 마지막에 넣은 것을 먼저 꺼낸다.

- `Ctrl + Z` 되돌리기, 함수 호출 기록, 괄호 검사 등에 쓰인다.

```python
s = []
s.append(1)    # 넣기
s.pop()        # 맨 위 꺼내기
```

### 큐 (Queue) — FIFO

> 비유: **줄 서기**. 먼저 온 것이 먼저 나간다.

- 프린터 대기열, 게임 매칭 대기열, BFS 탐색 등에 쓰인다.

```python
from collections import deque

q = deque([1, 2, 3])
q.popleft()      # 앞에서 꺼내기
q.appendleft(0)  # 앞에 넣기
```

- 리스트의 `pop(0)`은 O(n)이지만 `deque.popleft()`는 O(1)이므로 큐에는 `deque`를 쓴다.

### Counter — 개수 집계

```python
from collections import Counter

Counter("hello").most_common(1)   # [('l', 2)]
```

### defaultdict — 기본값이 있는 딕셔너리

없는 키에 접근해도 `KeyError`가 발생하지 않는다.

```python
from collections import defaultdict

d = defaultdict(list)
d['새키'].append(1)    # 에러 없이 동작한다
```

## 9. 자주 하는 실수 모음

| 실수 | 결과 | 올바른 방법 |
|---|---|---|
| `b = a` | 복사가 아닌 별명 | `b = a.copy()` |
| `[[0]*3]*3` | 같은 리스트 3번 참조 | `[[0]*3 for _ in range(3)]` |
| `s = {}` | 빈 딕셔너리 생성 | `s = set()` |
| `t = (1)` | 정수 1 | `t = (1,)` |
| `b = a.sort()` | `b`가 `None` | `b = sorted(a)` |
| `d['없는키']` | `KeyError` | `d.get('없는키', 기본값)` |
| 반복 중 `remove()` | 요소 건너뜀 | 컴프리헨션으로 재생성 |
