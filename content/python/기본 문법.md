## 1. 변수

```python

s = "hello"         # 문자열 str
```

## 5. 문자열 포맷 (f-string)

```python
name = "김"
score = 95.567

f"{name}님 {score}점"       # 김님 95.567점
f"{score:.1f}"              # 95.6        소수 1자리
f"{score:.0f}"              # 96          정수로 반올림
f"{1000000:,}"              # 1,000,000   천단위 콤마
f"{name:>10}"               # 오른쪽 정렬
f"{name:<10}"               # 왼쪽 정렬
f"{name:^10}"               # 가운데 정렬
```

## 7. 반복문

### for

```python
for i in range(5):          # 0 1 2 3 4
for i in range(1, 6):       # 1 2 3 4 5
for i in range(0, 10, 2):   # 0 2 4 6 8
for i in range(5, 0, -1):   # 5 4 3 2 1

for item in [10, 20, 30]:   # 리스트 순회
    print(item)

for ch in "abc":            # 문자열 순회
    print(ch)
```

**같이 쓰면 편한 것**

```python
for i, v in enumerate(lst):      # 번호와 값을 동시에
    print(i, v)

for a, b in zip(names, ages):    # 두 리스트를 동시에
    print(a, b)

for k, v in d.items():           # 딕셔너리 키와 값
    print(k, v)
```

### while

```python
while x < 10:
    x += 1

while True:
    if 끝조건:
        break
```

### 반복 제어

```python
break       # 반복 즉시 중단
continue    # 이번 회차 건너뛰고 다음으로
pass        # 아무것도 안 함 (자리만 채움)
```

### 이중 반복문

```python
for i in range(1, 4):
    for j in range(1, 4):
        print(i, j)
```

## 9. 예외 처리

```python
try:
    x = int(input())
except ValueError:
    print("숫자가 아닙니다")
except Exception as e:
    print("에러:", e)
else:
    print("에러 없을 때만 실행")
finally:
    print("무조건 실행")
```

**자주 보는 에러**

| 에러 | 원인 |
|---|---|
| `SyntaxError` | 문법 오류 (콜론·괄호 빠짐) |
| `IndentationError` | 들여쓰기 잘못됨 |
| `NameError` | 없는 변수 사용 |
| `TypeError` | 타입이 안 맞음 (`"1" + 1`) |
| `ValueError` | 값이 잘못됨 (`int("abc")`) |
| `IndexError` | 리스트 범위 벗어남 |
| `KeyError` | 딕셔너리에 없는 키 |
| `ZeroDivisionError` | 0으로 나눔 |

## 10. 파일 입출력

```python
# 쓰기
with open("a.txt", "w", encoding="utf-8") as f:
    f.write("안녕\n")

# 읽기
with open("a.txt", "r", encoding="utf-8") as f:
    text = f.read()             # 전체를 문자열로

with open("a.txt", encoding="utf-8") as f:
    for line in f:              # 한 줄씩
        print(line.strip())
```

**모드**

| 모드 | 뜻 |
|---|---|
| `"r"` | 읽기 (기본) |
| `"w"` | 새로 쓰기 (기존 내용 삭제) |
| `"a"` | 이어 쓰기 |

## 12. 클래스

```python
class Person:
    def __init__(self, name, age):    # 생성자
        self.name = name
        self.age = age

    def hello(self):                  # 메소드 (첫 인자는 항상 self)
        print(f"안녕 {self.name}")

p = Person("김", 20)
p.hello()
print(p.name)
```

**상속**

```python
class Student(Person):
    def __init__(self, name, age, school):
        super().__init__(name, age)   # 부모 생성자 호출
        self.school = school
```
